# SUI 样式开发任务单（给 Codex）

框架已搭好。本文列出需要逐项完成的控件样式。**一次只做一个任务，做完在 Gallery 里看一遍再做下一个。**

## 0. 通用规则（所有任务必须遵守）

1. 只修改本任务指定的文件，以及 Gallery 中对应页面（用于展示）。
2. **样式文件中不得出现颜色字面量**（`#xxxxxx`、`White`、`Black`、`Transparent` 以外的命名色）。颜色只能引用 `Themes/Colors.xaml` 中的 `SUI.Brush.*`，用 `{StaticResource ...}`。需要新颜色时，先在 `Colors.xaml` 增加并说明。
3. 字体、字号、圆角、间距只引用 `Colors.xaml` 中的 `SUI.Font.*`、`SUI.Radius.*`、`SUI.Space.*`、`SUI.Control.Height`，不要写死。
4. **隐式样式**：每个原生控件写一个无 `x:Key` 的 `<Style TargetType="Button">`，宿主合并后自动生效。**显式变体**用 `BasedOn="{StaticResource {x:Type Button}}"` 派生并加 key，命名 `SUI.{控件}.{变体}`。
5. 使用 `ControlTemplate` 时必须覆盖：Normal、MouseOver、Pressed（若适用）、Focused（键盘焦点可见，用 `SUI.Brush.Focus` 边框）、Disabled（文字用 `SUI.Brush.TextDisabled`，背景用 `SUI.Brush.Disabled`，**不使用 `Opacity`**）。
6. 不使用 `DropShadowEffect`（仅 ToolTip、Popup 下拉、Menu 弹出层允许，且 `BlurRadius` ≤ 12）。
7. 不写代码后置，不新增 C# 类，不新增 NuGet 包。
8. 不要改 `Colors.xaml` 中已有 key 的名字；不要改 `SUIStyles.xaml` 的合并顺序（Colors 必须第一）。
9. 默认开启 `SnapsToDevicePixels="True"`；模板层级尽量浅。
10. 每个任务完成后运行 `dotnet build SUI.slnx`，必须 0 错误 0 警告，再提交结果。
11. 不要把 `Themes/Generic.xaml` 当作普通样式文件使用；它只放自定义控件默认样式。

## 1. 视觉基准（便于判断“长得对不对”）

- 整体接近 Windows 11 浅色：窗口底 `Background`，输入框/卡片 `Surface`，1px `Border` 边框，控件圆角 `Radius.Control`（4）。
- 控件高度 `Control.Height`（32），文字垂直居中，水平内边距约 `Space.3`（12）。
- Hover 底色 `Hover`，Pressed 底色 `Pressed`。主按钮 Hover 用 `AccentHover`，Pressed 用 `AccentPressed`。
- 输入类控件聚焦时：底边加粗为 2px `Accent`，其余边保持 `Border`（Fluent 风格）。
- 选中项：底色 `Selected`，文字保持 `Text`，左侧可加 3px `Accent` 竖条（仅列表/树/导航使用）。

## 2. 任务清单（按顺序）

### T1 Button — `Styles/ButtonStyles.xaml`

- 隐式：`Button`、`ToggleButton`。默认：`Surface` 底、`Border` 边框、圆角 4、MinHeight 32、Padding `12,0`。
- 状态：Hover `Hover` 底 + `BorderHover` 边；Pressed `Pressed` 底；Disabled 见通用规则；Focused 2px `Focus` 外框。
- `ToggleButton` 的 `IsChecked=True`：`Selected` 底 + `Accent` 边框。
- 显式变体：
  - `SUI.Button.Primary`：`Accent` 底、`TextOnAccent` 字、无边框，Hover/Pressed 用 `AccentHover/AccentPressed`。
  - `SUI.Button.Ghost`：透明底、无边框，Hover `Hover` 底。
  - `SUI.Button.Danger`：`Danger` 底、`TextOnAccent` 字（Hover/Pressed 可复用 Opacity 之外的方案：新增 `DangerHover` / `DangerPressed` 到 Colors.xaml）。
- Gallery：`ButtonsPage` 展示所有变体及禁用态（替换页面内的占位注释）。
- 验收：Tab 键可见焦点；按钮内中文居中不被裁切；Disabled 下无悬停效果。

### T2 TextBox / PasswordBox — `Styles/TextBoxStyles.xaml`

- 隐式：`TextBox`、`PasswordBox`。`Surface` 底、1px `Border`、圆角 4、MinHeight 32、`VerticalContentAlignment=Center`、Padding `10,0`（多行 TextBox 通过 `AcceptsReturn` 触发时用 `Padding 10,6`，用 Trigger 实现）。
- 状态：Hover 边框 `BorderHover`；Focused 底边 2px `Accent`；ReadOnly 底 `SurfaceAlt`；Disabled 见通用规则；`Validation.HasError` 时边框 `Danger`，且设置 `Validation.ErrorTemplate` 为空模板（不显示默认红框），错误提示通过 ToolTip 显示 `(Validation.Errors)[0].ErrorContent`。
- 必须保留 `PART_ContentHost`（TextBox）；PasswordBox 同样。
- 验收：中文输入法候选框位置正常；选区颜色可读（`SelectionBrush` 用 `Accent`，`SelectionOpacity` 0.3 即可）。

### T3 ScrollBar / ScrollViewer — `Styles/ScrollBarStyles.xaml`

- 隐式：`ScrollBar`。细滚动条：宽/高 10，滑块圆角 3，轨道透明；滑块颜色 `BorderHover`，Hover/拖动时 `TextSecondary`。
- 必须同时支持垂直与水平（用 Trigger on `Orientation`）。保留 `PART_Track`、上下/左右 `RepeatButton`（可以隐藏箭头按钮，但命令 `LineUp/LineDown/PageUp/PageDown` 要保留）。
- 同时定义 `ScrollViewer` 隐式样式，使用该滚动条，右下角 `Corner` 透明。
- 验收：DataGrid、ListBox、TextBox 多行、ComboBox 下拉里的滚动条外观一致；鼠标滚轮与拖动正常。

### T4 ComboBox — `Styles/ComboBoxStyles.xaml`

- 隐式：`ComboBox`、`ComboBoxItem`。外观同 TextBox（高 32、1px 边框、圆角 4）；右侧下拉箭头用 `Path`（Geometry 形如 `M 0,0 L 4,4 L 8,0`，Stroke `TextSecondary`，1.5px），不用图标字体。
- 下拉面板：`Popup` 内 `Border`，`Surface` 底、`Border` 边框、圆角 `Radius.Panel`（8）、轻阴影（`BlurRadius` ≤ 12、Opacity ≤ 0.2），最大高度用 `MaxDropDownHeight`，内部使用 `ScrollViewer`。
- `ComboBoxItem`：MinHeight 32，Hover `Hover` 底，选中 `Selected` 底，Disabled 见通用规则。
- 必须同时支持 `IsEditable=True`（含 `PART_EditableTextBox`，样式去边框、透明底）与不可编辑模式。
- 验收：键盘方向键切换、Esc 关闭、可编辑模式能输入；下拉面板圆角不被内容矩形遮挡（使用 `ClipToBounds` 或内层 `Border` 圆角）。

### T5 CheckBox / RadioButton — `Styles/CheckRadioStyles.xaml`

- 隐式：`CheckBox`、`RadioButton`。方框 18×18、圆角 4（Radio 为圆形 18×18），未选 `Surface` 底 + `BorderHover` 边；选中 `Accent` 底，CheckBox 内为白色对勾 `Path`（`TextOnAccent`），Radio 为 8px 白色圆点。
- `IsThreeState` 的不定态：CheckBox 显示白色短横。
- 状态：Hover 边框变 `TextSecondary`；Pressed 同 Accent 的 `AccentPressed`；Focused 外框 `Focus`；Disabled 见通用规则。内容（文字）与框间距 `Space.2`。
- **不要修改** `Styles/SwitchCheckBoxStyle.xaml`（由单独任务 F2 处理），也不要让隐式 `CheckBox` 样式影响 `SwitchCheckBoxStyle`（它自带模板，不使用 BasedOn，互不影响）。
- 验收：键盘 Space 切换；Focused 可见。

### T6 TabControl — `Styles/TabControlStyles.xaml`

- 隐式：`TabControl`、`TabItem`。顶部标签：TabItem 高 36、Padding `12,0`，选中项底部 2px `Accent` 下划线、文字 `Text`；未选 `TextSecondary`，Hover `Hover` 底；内容区 `Surface` 底、无外边框（仅顶部 1px `Border` 分隔线）。
- 支持 `TabStripPlacement=Top`（必须）；Left/Right/Bottom 可不支持，但不得崩溃。
- 验收：标签过多时按 WPF 默认换行/截断行为即可，不需要滚动。

### T7 ListBox — `Styles/ListBoxStyles.xaml`

- 隐式：`ListBox`、`ListBoxItem`。ListBox：`Surface` 底、1px `Border`、圆角 4；Item：MinHeight 32、Padding `10,0`、圆角 4、Margin `2`。
- 状态：Hover `Hover` 底；选中 `Selected` 底；窗口失焦时选中项仍保持 `Selected` 底（不要像系统默认变灰）；Focused 项用 1px `Focus` 内边框；Disabled 见通用规则。
- **注意**：`SUINavigationView` 内部的 ListBox 使用自己的显式样式（`SUINavigationListBoxStyle`、`SUINavigationItemContainerStyle`），不得受隐式样式影响——验证 Gallery 导航仍正常。
- 验收：多选（`SelectionMode=Extended`）下选中可辨认。

### T8 Menu / ContextMenu / MenuItem / Separator — `Styles/MenuStyles.xaml`

- 隐式：`Menu`、`ContextMenu`、`MenuItem`、`Separator`。
- Menu：`Surface` 底、无边框、高 32；顶级 MenuItem Hover `Hover` 底、圆角 4。
- ContextMenu 与下拉子菜单面板：`Surface` 底、`Border` 边框、圆角 8、轻阴影（同 T4 限制）、内边距 4。
- MenuItem 条目：高 32、圆角 4；布局为 图标列（可空，宽 20）｜标题｜快捷键（`InputGestureText`，`TextSecondary`）｜子菜单箭头；`IsChecked` 显示对勾；Hover `Hover` 底；Disabled 见通用规则。
- Separator：1px `Border`，上下 Margin 4。
- 验收：Gallery 容器页的菜单与按钮右键菜单显示正常；子菜单可展开；Alt 访问键不受影响。

### T9 ToolTip — `Styles/ToolTipStyles.xaml`

- 隐式：`ToolTip`。`Surface` 底、1px `Border`、圆角 4、Padding `8,4`、文字 `Text`、字号 `Font.Size.Caption`；轻阴影（同限制）；`MaxWidth` 320，文字自动换行（`TextBlock.TextWrapping`）。
- 验收：多行 ToolTip、字符串与自定义内容的 ToolTip 都能显示。

### T10 ProgressBar — `Styles/ProgressBarStyles.xaml`

- 隐式：`ProgressBar`。高 4、圆角 2、轨道 `Border` 色、指示条 `Accent`。
- 必须支持：确定进度（`PART_Track` + `PART_Indicator`）与不确定进度（`IsIndeterminate=True`，用 `Storyboard` 让 `Accent` 条沿轨道往复移动，≤1.5s 周期，ease-in-out，仅动 `RenderTransform`）。
- 验收：Value 0/50/100 显示正确；不确定状态动画流畅，且控件不可见（`Visibility=Collapsed`）时动画停止。
