# SUI 使用手册

本文档对应当前仓库中的 SUI 实现，介绍项目接入方式、控件 API、样式资源和常见使用模式。

SUI 是供 Windows 桌面应用使用的 WPF 控件与样式库，目标框架是 `net48`、`net8.0-windows`、`net10.0-windows`。推荐通过 [NuGet 包 SUI](https://www.nuget.org/packages/SUI) 接入；需要修改库源码或联调时，也可以使用本地 `ProjectReference`。

以下 NuGet 示例以当前已发布的 `0.1.1` 版本为例。手册正文按当前仓库主干源码编写，会在对应章节标明 `0.1.1 已提供` 与 `0.1.1 之后（主干源码）新增` 的能力边界；安装特定版本或使用尚未发版的新特性时，请核对对应版本的发布说明或改用本地源码引用。

## 快速开始

### 环境要求

- 主要面向 Windows 10 / 11，宿主项目启用 WPF。
- 当前源码同时生成 `net48`、`net8.0-windows`、`net10.0-windows` 三个版本：分别供 .NET Framework 4.8 / 4.8.1、.NET 8 / 9、.NET 10 项目使用；现代 .NET 5～7 不在本次支持范围内。
- 编译仓库源码需要 .NET 10 SDK，以及 .NET Framework 4.8 目标包（Developer Pack / 引用程序集）。仓库明确使用 C# 12 编译；应用通过 NuGet 引用已编译的库时，无需因此升级其 C# 语言版本。
- 运行用户只需应用对应的运行时：Framework 应用使用 4.8 / 4.8.1，现代 WPF 应用使用对应的 .NET Desktop Runtime；不要求安装 SDK。自包含发布由宿主应用决定。

- **版本能力对照**：NuGet 上当前稳定版本为 `0.1.1`（对应提交 `16772e1`），而本仓库主干源码在此之后继续新增了工作台与紧凑表单能力。接入前可先核对下表：

### 1. 通过 NuGet 安装 SUI

在你的 WPF 项目 `.csproj` 所在目录执行：

```powershell
dotnet add package SUI --version 0.1.1
```

也可以在 Visual Studio 的“管理 NuGet 程序包”中搜索 `SUI`，确认作者为 `RobertCXC` 后安装。包地址：[nuget.org/packages/SUI](https://www.nuget.org/packages/SUI)。

NuGet 会添加包引用，并在还原、构建时自动引用包中的 `SUI.dll`。对应的项目配置如下（与上面的安装命令二选一）：

```xml
<ItemGroup>
    <PackageReference Include="SUI" Version="0.1.1" />
</ItemGroup>
```

接下来合并样式并使用控件即可；只有运行仓库 Gallery 或修改库源码时才需要克隆仓库。

### 2. 在 `App.xaml` 合并样式

把 `SUIStyles.xaml` 合并到应用级资源中。这样按钮、文本框、列表等原生 WPF 控件会自动采用 SUI 外观：

```xml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="/SUI;component/SUIStyles.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

### 3. 在页面中使用

将 `SUI` 命名空间映射到 XAML 前缀，然后像使用普通 WPF 控件一样组合库控件和原生控件：

```xml
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:sui="clr-namespace:SUI;assembly=SUI">
    <StackPanel Margin="24">
        <TextBlock Margin="0,0,0,12" Text="欢迎使用 SUI" />
        <Button Content="保存" Style="{StaticResource SUI.Button.Primary}" />
        <sui:SUICard
            Margin="0,16,0,0"
            Title="项目状态"
            Description="SUI 控件可以和 WPF 原生控件组合使用。"
            IconText="S" />
    </StackPanel>
</Window>
```

`SUINavigationView` 使用 `SUI.Navigation` 命名空间，导航和右侧页面如何映射由宿主应用决定。普通原生控件的样式资源、导航示例和全部属性见本手册后续章节。

### 4. 运行控件示例

克隆仓库后，在仓库根目录执行以下命令可运行 SUI Gallery：

```powershell
dotnet run --project .\samples\SUI.Gallery\SUI.Gallery.csproj -f net10.0-windows
```

将 `-f` 改为 `net48` 或 `net8.0-windows` 可检查对应版本；Gallery 首页会显示当前编译目标。GitHub Release 将分别提供三个框架的 Gallery ZIP，现代 .NET 版本为依赖框架的 win-x64 发布，需安装对应 Desktop Runtime。

Gallery 提供概览、按钮与命令、输入与选择、数据与布局、容器与反馈、应用导航、设计基础七个页面。21 组展示均使用真实 SUI 控件，可以直接体验外观、交互状态和操作反馈。Gallery 专注运行效果，接入方法、代码示例与 API 参考统一在本手册中查阅。

- **快速定位**：按 `Ctrl+K` 搜索中文名称、控件名或样式名（例如 `Button`、`开关`、`DataGrid`），按 `Enter` 打开首个匹配分类，按 `Esc` 清空搜索。
- **交互体验**：按钮试验台可实时切换文字、视觉变体和禁用状态；输入页可以验证名称并保存演示设置；数据页提供 200 行数据、筛选、排序、多选与两个方向的布局调整；反馈页可以启动、暂停和重置模拟任务。
- **导航与设计**：导航页演示紧凑侧栏、固定底部入口、横向图文侧栏及入口状态；设计基础页展示实际主题的颜色、字体、圆角和间距效果。
- **状态保留**：切换分类会保留本次会话中的示例状态；离开反馈页时模拟任务自动暂停。所有操作只影响 Gallery 演示数据。

`FileUpload`、`TimePicker`、`DatePicker`、交互式 `SUICard` 与可关闭滚动 `TabControl` 均已在 Gallery 对应页面提供完整交互示例。

## 接入项目

### NuGet 包引用（推荐）

常规应用集成使用 [SUI NuGet 包](https://www.nuget.org/packages/SUI)。在宿主 WPF 项目目录执行：

```powershell
dotnet add package SUI --version 0.1.1
```

如果希望安装 NuGet 源中的最新稳定版，可省略 `--version`：

```powershell
dotnet add package SUI
```

安装命令会写入 `PackageReference`，NuGet 负责还原和管理 `SUI.dll` 引用。版本号可在 NuGet 包页面核对；使用新版本前请核对其功能与目标框架。

### 本地项目引用（源码开发）

需要修改 SUI 源码或验证仓库中尚未发布的改动时，可以克隆仓库，并在宿主 WPF 项目的 `.csproj` 中引用库项目：

```xml
<ItemGroup>
    <ProjectReference Include="..\SUI\SUI.csproj" />
</ItemGroup>
```

路径需要根据宿主项目和 SUI 的实际目录层级调整。仓库中的 Gallery 使用这种方式，便于实时验证库的改动。同一宿主项目选择 `PackageReference` 或 `ProjectReference` 中的一种，避免同时引用两份 SUI。

### 引用命名空间

NuGet 包引用和本地项目引用都使用相同的程序集名称 `SUI`。XAML 中的 `assembly=SUI` 表示程序集名称，不表示安装来源，也不是 DLL 文件路径。

普通控件位于 `SUI` 命名空间：

```xml
xmlns:sui="clr-namespace:SUI;assembly=SUI"
```

导航控件位于 `SUI.Navigation` 命名空间：

```xml
xmlns:suiNav="clr-namespace:SUI.Navigation;assembly=SUI"
```

### 合并公共样式

SUI 为 WPF 原生控件提供了一整套隐式样式。在 `App.xaml` 中合并一次 `SUIStyles.xaml`，整个应用内的 `Button`、`TextBox`、`ComboBox`、`DataGrid` 等控件就会自动换上 SUI 外观，无需逐个指定 `Style`：

```xml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="/SUI;component/SUIStyles.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

`SUINavigationView` 的默认样式位于 [`../Themes/Generic.xaml`](../Themes/Generic.xaml)，WPF 会通过默认样式键自动加载，不需要在应用中重复合并。

## SUIBadge 状态徽标

命名空间为 SUI，沿用 SUICard、SUINavigationView 的命名方式。用于连接状态、任务结果等简短信息，默认显示浅色胶囊（圆角半径为实际高度的一半，两端为半圆，上下边保持平直）；它是非交互 ContentControl，不占用 Tab 焦点，不提供点击、关闭、通知计数或连接逻辑。自 NuGet `0.0.9` 起提供。

声明 `xmlns:sui="clr-namespace:SUI;assembly=SUI"` 后使用：

```xml
<sui:SUIBadge Content="已连接" Variant="Success" Shape="Pill" />
<sui:SUIBadge Content="连接中" Variant="Info" />
<sui:SUIBadge Content="已断开" Variant="Danger" Shape="Rounded" />
<sui:SUIBadge Content="{Binding StatusText}" Variant="{Binding StatusVariant}" />
<!-- Content 为 object 类型，格式化数字或字符串请使用 ContentStringFormat -->
<sui:SUIBadge Content="{Binding Count}" ContentStringFormat="共 {0} 项" Variant="Neutral" />
```

> **提示**：由于 `SUIBadge` 继承自 `ContentControl`，`Content` 属性类型为 `object`，WPF 不会对 `{Binding Count, StringFormat='共 {0} 项'}` 应用 `StringFormat`。需要格式化显示时，请使用 `ContentStringFormat`（如上例）或在 ViewModel 中暴露格式化后的字符串属性。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| Content | object | null | 继承属性；支持字符串、UIElement 和 ContentTemplate |
| Variant | SUI.BadgeVariant | Neutral | Neutral、Success、Warning、Danger、Info |
| Shape | SUI.BadgeShape | Pill | Pill 胶囊、Rounded 圆角矩形 |
| Padding | Thickness | 10,3 | 内容内边距 |
| FontSize | double | 12 | 默认引用 SUI.Font.Size.Caption |
| IsEnabled | bool | true | 禁用时使用 Disabled / TextDisabled 主题色 |

Content、Variant、Shape 支持绑定和运行时更新；连接中由宿主设置为 Info，不自动探测设备或播放动画。Background、Foreground、BorderBrush、BorderThickness、FontSize 可按普通 WPF 属性覆盖，局部颜色优先于语义色及禁用色。默认水平靠左、垂直居中，尺寸由内容决定，宿主可设置对齐和宽高。

自定义内容应设置 AutomationProperties.Name；字符串内容默认作为自动化名称。徽标应保留状态文字，避免仅靠颜色表达含义。

模板通过 Themes/Generic.xaml 自动合并 Styles/BadgeStyles.xaml 加载；依赖 SUI.Brush.SuccessSubtle、WarningSubtle、DangerSubtle 浅色背景和现有语义文字色。Gallery 的“容器与反馈”页展示全部语义颜色、两种形状、禁用、自定义内容与动态绑定。

设计参考：[Fluent UI Badge](https://learn.microsoft.com/en-us/fluent-ui/web-components/components/badge) 的通用状态用途，以及 [Ant Design Badge](https://ant.design/components/badge) 的语义状态。此 API 按 SUI 命名约定独立实现。

## `SUIInfoBar` 与 `SUIToastHost` 提示控件

`SUIInfoBar` 与 `SUIToastHost` 位于 `SUI` 命名空间，共用语义级别枚举 `InfoSeverity`，颜色直接复用 `Themes/Colors.xaml` 中的语义色与浅色背景画刷。

### 语义级别 `InfoSeverity`

| 枚举值 | 语义 | `SUIInfoBar` 背景 / 图标色 | `SUIToastHost` 左侧指示条 |
| --- | --- | --- | --- |
| `Info`（默认） | 常规提示、说明 | `SUI.Brush.Selected` / `SUI.Brush.Info` | `SUI.Brush.Info` |
| `Success` | 操作成功、保存完成 | `SUI.Brush.SuccessSubtle` / `SUI.Brush.Success` | `SUI.Brush.Success` |
| `Warning` | 环境变量覆盖、占位警告 | `SUI.Brush.WarningSubtle` / `SUI.Brush.Warning` | `SUI.Brush.Warning` |
| `Error` | 校验失败、连接异常 | `SUI.Brush.DangerSubtle` / `SUI.Brush.Danger` | `SUI.Brush.Danger` |

### `SUIInfoBar` 页面内嵌提示条

`SUIInfoBar` 是轻量 `ContentControl`，默认水平拉伸、自动换行。支持仅显示 `Message`、同时显示粗体 `Title` 与 `Message`、右侧放置操作控件（`ActionContent`），以及在下方通过 `Content` 放入自定义内容。

```xml
<!-- 1. 可关闭的提示横幅 + 右侧操作按钮（支持 MVVM 双向绑定 IsOpen） -->
<sui:SUIInfoBar
    Title="环境变量覆盖"
    Message="LOG_LEVEL 当前由环境变量接管，页面修改将在移除环境变量后生效。"
    Severity="Warning"
    IsOpen="{Binding ShowEnvWarning}"
    Closed="OnInfoBarClosed">
    <sui:SUIInfoBar.ActionContent>
        <Button Content="查看说明" Command="{Binding OpenHelpCommand}" />
    </sui:SUIInfoBar.ActionContent>
</sui:SUIInfoBar>

<!-- 2. 不可关闭的静态状态提示 -->
<sui:SUIInfoBar
    Title="校验失败"
    Message="单文件大小上限必须在 1 到 1024 MiB 之间。"
    Severity="Error"
    IsClosable="False" />
```

| 属性/事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Title` | `string?` | `null` | 粗体标题，为空时不占位。 |
| `Message` | `string?` | `null` | 提示正文，支持自动换行，为空时不占位。 |
| `Severity` | `InfoSeverity` | `InfoSeverity.Info` | 控制图标、浅色底色与图标语义色。 |
| `ActionContent` | `object?` | `null` | 显示在关闭按钮左侧的自定义操作元素（如 `Button`）。 |
| `Content` | `object?` | `null` | 显示在标题/消息下方的附加自定义内容，无内容时自动折叠。 |
| `IsClosable` | `bool` | `true` | 是否显示右上角关闭按钮。 |
| `IsOpen` | `bool` | `true` | 是否显示横幅，支持双向绑定；设为 `false` 时控件 `Visibility` 变为 `Collapsed`。 |
| `Closed` | 路由事件 | — | 用户点击内置关闭按钮时触发。 |

### `SUIToastHost` 轻量非阻塞提示宿主

将 `SUIToastHost` 放在页面或主窗口根 `Grid` 的最末子节点，默认靠右下角对齐（可通过 `HorizontalAlignment`、`VerticalAlignment`、`Margin` 调整位置）。无通知时容器不占用交互命中区域，不会拦截下方控件的鼠标点击。

```xml
<Grid>
    <!-- 主页面内容 -->
    <ScrollViewer>
        <!-- ... -->
    </ScrollViewer>

    <!-- 叠加在最上层的轻提示宿主 -->
    <sui:SUIToastHost x:Name="ToastHost" Duration="0:0:3" MaxItems="4" />
</Grid>
```

```csharp
// 1. 弹出默认 3 秒自动消失的成功提示
ToastHost.Show("配置已保存到本地。", InfoSeverity.Success, "保存成功");

// 2. 自定义本条提示停留时间（传入 TimeSpan.Zero 则不自动消失，仅手动关闭）
var toast = ToastHost.Show("后台正在同步索引…", InfoSeverity.Info, duration: TimeSpan.FromSeconds(5));

// 3. 提前手动关闭单条或清空全部
ToastHost.Dismiss(toast);
ToastHost.Clear();
```

| 成员 | 类型 / 签名 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Duration` | `TimeSpan` | `3 秒` | 默认自动消失延时。 |
| `MaxItems` | `int` | `4` | 同时展示的最大条数（须大于 `0`）；超出时自动移除最早一条。 |
| `Show(...)` | `SUIToastMessage Show(string message, InfoSeverity severity = Info, string? title = null, TimeSpan? duration = null)` | — | 追加一条通知并返回消息对象；`duration` 为 `TimeSpan.Zero` 时保持显示直到手动关闭。 |
| `Dismiss(...)` | `void Dismiss(SUIToastMessage? item)` | — | 关闭指定通知。 |
| `Clear()` | `void Clear()` | — | 清空当前所有通知。 |

## `SUIDialog` 对话框

`SUIDialog` 是采用 SUI Fluent 外观的轻量模态窗口，用于替代系统原生 `MessageBox`，保持按钮风格、圆角、字号与色彩体系一致。内置无边框拖拽标题栏、语义图标、`Esc` 快捷取消以及点击右上角关闭按钮。

- **焦点与防误触约定**：当 `isDanger: true` 时，主按钮自动使用 `SUI.Button.Danger` 样式且**不设为 `IsDefault`**，避免用户误按 `Enter` 触发不可逆操作；常规确认（`isDanger: false`）主按钮为 `SUI.Button.Primary` 且支持 `Enter` 确认。`Esc` 键与取消按钮始终触发 `SUIDialogResult.Cancel`。
- **自动居中**：`owner` 传入 `null` 时，自动查找当前处于激活且可见的主窗口作为 `Owner` 并居中；若无可用窗口则屏幕居中。关闭后焦点由 WPF 模态机制自动交还父窗口。

### 常用接入方式

```csharp
// 1. 常规双按钮确认（返回 bool）
if (SUIDialog.Confirm(
    message: "确定将所有配置恢复为默认值吗？",
    title: "恢复默认设置",
    confirmText: "恢复默认",
    cancelText: "取消",
    owner: Window.GetWindow(this)))
{
    ResetDefaults();
}

// 2. 危险操作二次确认（isDanger: true 使用红色 Danger 按钮且不绑定回车默认触发）
if (SUIDialog.Confirm(
    message: "将永久删除 128 MB 历史日志且无法恢复，是否继续？",
    title: "清理历史日志",
    confirmText: "确认清理",
    cancelText: "取消",
    isDanger: true))
{
    ClearLogs();
}

// 3. 三按钮选择（返回 SUIDialogResult: Primary / Secondary / Cancel / None）
var result = SUIDialog.Show(
    content: "当前配置尚未保存，关闭前要保存更改吗？",
    title: "未保存的更改",
    primaryText: "保存",
    secondaryText: "不保存",
    cancelText: "取消",
    severity: InfoSeverity.Warning);

// 4. 自定义弹窗内容（传入任意 WPF UIElement，如输入框）
var input = new TextBox { Width = 280, Text = "default-profile" };
if (SUIDialog.Show(input, title: "新建配置名称", primaryText: "创建", cancelText: "取消") == SUIDialogResult.Primary)
{
    CreateProfile(input.Text);
}

// 5. 宽屏表单与关闭前校验拦截（SUIDialogOptions）
var formInput = new TextBox { Width = 420 };
var formResult = SUIDialog.Show(formInput, new SUIDialogOptions
{
    Title = "新建升级方案",
    PrimaryText = "创建",
    CancelText = "取消",
    MaxWidth = 640,
    Closing = (_, args) =>
    {
        if (args.Result == SUIDialogResult.Primary && string.IsNullOrWhiteSpace(formInput.Text))
        {
            args.Cancel = true;
            args.ErrorMessage = "方案名称不能为空，请输入后重试。";
        }
    },
});
```

### API 说明

| 成员 | 签名 / 枚举值 | 说明 |
| --- | --- | --- |
| `SUIDialogResult` | `None`、`Primary`、`Secondary`、`Cancel` | 分别对应窗口直接关闭、主按钮、次按钮、取消按钮/`Esc`/右上角关闭。 |
| `SUIDialog.Confirm(...)` | `bool Confirm(string message, string title = "确认操作", string confirmText = "确定", string cancelText = "取消", bool isDanger = false, Window? owner = null)` | 快捷双按钮确认；点击主确认按钮返回 `true`，其余返回 `false`。 |
| `SUIDialog.Show(...)` | `SUIDialogResult Show(object content, string title = "提示", string? primaryText = "确定", string? secondaryText = null, string? cancelText = null, InfoSeverity severity = InfoSeverity.Info, bool isDanger = false, Window? owner = null)` | 完整可配置模态框；传 `null` 或空字符串的按钮不会渲染。 |
| `SUIDialog.Show(content, options)` | `SUIDialogResult Show(object content, SUIDialogOptions options)` | 按 `SUIDialogOptions` 配置宽高限制、内容区 `ScrollViewer`、`Closing` 校验拦截与 `PrimaryCommand` / `PrimaryEnabledBinding`。 |
| `SUIDialog` 实例成员 | `DialogClosing`、`ValidationError`、`SetValidationError(string?)` | 支持先构造 `new SUIDialog(content, options)` 再挂接事件并调用 `ShowDialog()`，原地显示/清空底部错误横幅。 |

`SUIDialogOptions` 核心配置项：

- **尺寸与滚动**：`Width`、`MinWidth`（默认 `360`）、`MaxWidth`（默认 `480`）、`Height`、`MinHeight`、`MaxHeight`（未指定时自动限制为屏幕工作区高度的 `85%`）、`UseScrollViewer`（默认 `true`，超长表单自动在内容区内滚动，标题栏与底部按钮栏保持固定）。
- **校验拦截与命令**：`Closing`（接收 `SUIDialogClosingEventArgs`，设 `e.Cancel = true` 阻止关闭，若同时设置 `e.ErrorMessage` 则自动在底部弹出红色 `SUIInfoBar` 原地提示）、`PrimaryCommand` / `PrimaryCommandParameter`（自动联动 `CanExecute` 禁用态，并仅在校验通过确认关闭前执行）与 `PrimaryEnabledBinding`。

## `SUINumberBox` 数值输入框

`SUINumberBox` 专为端口、单文件大小限制（MiB）、保留天数、超时毫秒与浮点阈值等数值参数设计，视觉与原生 `TextBox` 对齐（高 32、圆角 4、聚焦 2px 强调色底边）。

### 输入、步进与校验行为

- **允许输入中间态**：编辑过程中不强行覆盖文本，可自由删除、输入负号或小数点；仅在**失去焦点**或按 **`Enter`** 时解析并按 `[Minimum, Maximum]` 钳制、按 `DecimalPlaces` 四舍五入规范化。
- **撤销与步进**：按 `Esc` 放弃当前未提交编辑并恢复 `Value`；按 `↑` / `↓`、鼠标悬停且聚焦时滚动滚轮、或点击/长按右侧 `RepeatButton` 步进按钮，按 `Step` 增量立即更新 `Value`。达到上下限时对应步进按钮自动禁用。
- **空值策略**：`AllowEmpty="False"`（默认）时若清空后提交，会自动恢复为钳制后的有效数值（如 `Minimum` 或 `0`），适合绑定 MVVM 中的非空 `int` / `double` 属性；设为 `True` 时清空后提交 `null`，并显示 `PlaceholderText`。
- **紧凑与校验态**：支持 `Style="{StaticResource SUI.NumberBox.Compact}"`（28px 高度、`6,0` 内边距）；绑定产生 `Validation.HasError`（如 `INotifyDataErrorInfo`）时边框与聚焦底边切换为红色 `SUI.Brush.Danger`，并通过 `ToolTip` 显示首条错误信息。

```xml
<!-- 整型配置参数 -->
<sui:SUINumberBox
    Width="160"
    Minimum="1"
    Maximum="1024"
    Step="16"
    DecimalPlaces="0"
    Value="{Binding MaxFileSizeMiB}" />

<!-- 保留 2 位小数 -->
<sui:SUINumberBox
    Width="160"
    Minimum="0"
    Maximum="1"
    Step="0.05"
    DecimalPlaces="2"
    Value="{Binding Threshold}" />

<!-- 允许留空且隐藏步进按钮 -->
<sui:SUINumberBox
    Width="180"
    Minimum="1"
    Maximum="3650"
    AllowEmpty="True"
    ShowButtons="False"
    PlaceholderText="留空表示永久保留"
    Value="{Binding RetentionDays}" />
```

| 属性/事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Value` | `double?` | `0` | 当前数值，默认双向绑定，自动钳制到 `[Minimum, Maximum]`。 |
| `Minimum` / `Maximum` | `double` | `MinValue` / `MaxValue` | 最小与最大允许值（若颠倒会自动取区间两端）。 |
| `Step` | `double` | `1` | 步进按钮、键盘上下键与滚轮增量（须大于 `0`）。 |
| `DecimalPlaces` | `int` | `0` | 保留小数位数（`0`–`15`），`0` 为整数格式。 |
| `AllowEmpty` | `bool` | `false` | 是否允许提交空值为 `null`。 |
| `ShowButtons` | `bool` | `true` | 是否显示右侧上下步进按钮。 |
| `IsReadOnly` | `bool` | `false` | 只读状态，禁止文本输入与步进，底色切换为 `SurfaceAlt`。 |
| `PlaceholderText` | `string?` | `null` | 文本框为空时显示的占位提示文字。 |
| `ValueChanged` | 路由事件 | — | `Value` 变更时触发（`RoutedPropertyChangedEventArgs<double?>`）。 |

## `SUICard` 卡片控件

`SUICard` 是一个轻量信息与入口卡片控件，适合展示应用入口、状态摘要或功能概览。它继承自 `UserControl` 并实现 `ICommandSource`，既可作为静态信息卡片，也可开启点击交互（`IsInteractive="True"` 或绑定 `Command`），同时支持标题自动换行、Fluent 字形图标、状态徽标插槽与右侧操作插槽。

### 基本用法

```xml
<!-- 静态信息卡片 -->
<sui:SUICard
    Title="项目状态"
    Description="这是一个可复用的 WPF 卡片"
    IconText="S" />

<!-- 交互式入口卡片（带字形图标、状态徽标与操作插槽） -->
<sui:SUICard
    Title="串口调试与帧分析工具"
    Description="支持自定义波特率、十六进制收发与指令队列管理。"
    IconGlyph="&#xE839;"
    IsInteractive="True"
    Command="{Binding OpenToolCommand}"
    CommandParameter="serial">
    <sui:SUICard.BadgeContent>
        <sui:SUIBadge Content="需串口" Variant="Info" />
    </sui:SUICard.BadgeContent>
    <sui:SUICard.ActionContent>
        <Button Content="配置" Style="{StaticResource SUI.Button.Ghost}" Command="{Binding ConfigureCommand}" />
    </sui:SUICard.ActionContent>
</sui:SUICard>
```

### 属性与事件

| 属性 / 事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `IconSource` | `ImageSource?` | `null` | 图标图片。设置后会替换 `IconGlyph` 与 `IconText`。 |
| `IconGlyph` | `string?` | `null` | `Segoe Fluent Icons` 字形；非空且未设置 `IconSource` 时替换 `IconText`。 |
| `IconText` | `string` | `S` | 没有 `IconSource` 和 `IconGlyph` 时显示的占位文字。 |
| `IconColor` | `Brush` | `#4C79FF` | 左侧图标色块的背景画刷。 |
| `Title` | `string` | `标题` | 卡片标题，支持自动换行。 |
| `Description` | `string` | `略` | 卡片描述，支持自动换行；为空时自动折叠。 |
| `BadgeContent` | `object?` | `null` | 标题右侧状态徽标插槽（如 `SUIBadge`），为 `null` 时自动折叠。 |
| `ActionContent` | `object?` | `null` | 卡片右侧操作插槽（如按钮），为 `null` 时自动折叠；点击插槽内部元素不会误触发卡片自身的 `Click` / `Command`。 |
| `IsInteractive` | `bool` | `false` | 是否启用悬停/按下/键盘焦点视觉状态、手型光标与点击交互；设置 `Command` 时会自动视为可交互。 |
| `Command` / `CommandParameter` / `CommandTarget` | `ICommand?` 等 | `null` | 点击卡片或聚焦后按 `Enter` / `Space` 执行的命令；控件会自动监听 `CanExecuteChanged`，不可执行时禁用交互反馈（`IsClickable` 为 `false`）。 |
| `IsClickable` / `IsPressed` | `bool`（只读） | `false` | 分别指示卡片当前是否处于可交互态、是否正被按下；可点击时无障碍模式返回 `Button` 并支持 `IInvokeProvider`。 |
| `Click` | 路由事件 | — | 可交互卡片被点击或通过 `Enter` / `Space` 激活时触发。 |

### 数据绑定

所有上述属性都是依赖属性，可以直接绑定到 ViewModel：

```xml
<sui:SUICard
    Description="{Binding Description}"
    IconColor="{Binding AccentBrush}"
    IconGlyph="{Binding IconGlyph}"
    IconSource="{Binding IconSource}"
    IconText="{Binding IconText}"

    CommandParameter="{Binding}"
```

## `SUIStepper` 流程步骤条

`SUIStepper` 位于 `SUI` 命名空间，面向多阶段向导与任务流程（如固件远程升级、差分升级或初始化配置），支持步骤序号或 `IconGlyph` 图标、主标题与副标题，内置 `Pending` / `Active` / `Completed` / `Error` 四种语义状态、横向/纵向布局以及可选的「点击已完成步骤回看」能力。

### 用法与状态驱动模式

`SUIStepper` 支持两种状态驱动方式：

1. **按当前索引自动计算（`CurrentStepIndex >= 0`）**：只需绑定 `CurrentStepIndex`（0 起始）与可选 `IsCurrentStepError`，索引之前的步骤自动为 `Completed`，当前步为 `Active`（或 `Error`），之后为 `Pending`。
2. **由每个 `SUIStepItem.Status` 独立驱动（`CurrentStepIndex="-1"`，默认）**：适合需要为任意步骤单独标错或跳跃的复杂状态机。

```xml
<!-- 1. 索引驱动 + 开启已完成步骤点击回看 -->
<sui:SUIStepper
    CurrentStepIndex="{Binding CurrentStepIndex}"
    IsCurrentStepError="{Binding HasStepError}"
    AllowCompletedClick="True"
    StepClickCommand="{Binding JumpToStepCommand}"
    StepClicked="OnStepClicked">
    <sui:SUIStepItem Title="参数准备" Description="校验固件与分包大小" />
    <sui:SUIStepItem Title="启动传输" Description="下发升级启动指令" />
    <sui:SUIStepItem Title="顺序写块" Description="写入固件数据帧" />
    <sui:SUIStepItem Title="位图检漏" Description="检查缺块并补发" />
    <sui:SUIStepItem Title="执行升级" Description="重启并运行 APP" />
</sui:SUIStepper>

<!-- 2. 纵向步骤条 + 绑定 ObservableCollection<SUIStepItem> -->
<sui:SUIStepper Orientation="Vertical" ItemsSource="{Binding WizardSteps}" />
```

### API 说明

| 类型 / 成员 | 类型 / 签名 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `StepStatus` | `Pending`、`Active`、`Completed`、`Error` | — | 步骤四态枚举。 |
| `SUIStepper.Orientation` | `Orientation` | `Horizontal` | 排列方向（`Horizontal` 等宽横向步骤条 / `Vertical` 纵向步骤条）。 |
| `SUIStepper.CurrentStepIndex` | `int` | `-1` | 当前步骤（0 起始）；设为 `>= 0` 时自动推导各步骤四态，`-1` 时直接使用每项 `Status`。 |
| `SUIStepper.IsCurrentStepError` | `bool` | `false` | 配合 `CurrentStepIndex` 使用，将当前步骤显示为 `Error` 状态。 |
| `SUIStepper.AllowCompletedClick` | `bool` | `false` | 是否允许点击状态为 `Completed` 的步骤进行回看（开启后支持悬停、手型光标与键盘 Tab/`Enter`/`Space`）。 |
| `SUIStepper.StepClickCommand` | `ICommand?` | `null` | 点击可交互步骤时执行的命令，参数为对应数据项。 |
| `SUIStepper.StepClicked` | `EventHandler<SUIStepClickedEventArgs>` | — | 点击可交互步骤时触发的冒泡路由事件（含 `Item`、`Index`、`StepNumber`）。 |
| `SUIStepItem` 属性 | `Key`、`Title`、`Description`、`IconGlyph`、`Status`、`IsEnabled`、`IsClickable`、`ToolTip` | — | 内置实现 `INotifyPropertyChanged` 的步骤模型；`IsClickable` 为 `bool?`，可覆盖全局 `AllowCompletedClick` 策略。 |

## `SUIDateTimePicker` 日期时间选择器

| `IsReadOnly` | `bool` | `false` | 只读状态，禁止编辑与展开面板。 |
| `IsDropDownOpen` | `bool` | `false` | 控制联合弹出面板展开/收起，默认双向绑定。 |
| `AllowClear` | `bool` | `true` | 是否在弹出面板底部显示「清除」按钮。 |
| `SelectedDateTimeChanged` | 路由事件 | — | `SelectedDateTime` 变更时触发（`RoutedPropertyChangedEventArgs<DateTime?>`）。 |

支持通过 `Style="{StaticResource SUI.DateTimePicker.Compact}"` 切换为 28px 紧凑高度；绑定触发 `Validation.HasError` 时自动展示红色边框与 `ToolTip` 错误提示。

## `SUINavigationView` 导航控件

`SUINavigationView` 是一个“图标在上、标题在下”的窄侧边导航壳。它只负责导航项目、选中状态和左右布局；右侧页面由宿主应用提供，因此不会反向依赖业务页面。

### 基本接入

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}">
    <ContentControl Content="{Binding CurrentPage}" />
</suiNav:SUINavigationView>
```

### 准备导航数据

最简单的方式是使用 `SUINavigationItem`：

```csharp
using System.Collections.ObjectModel;
using SUI.Navigation;

public ObservableCollection<SUINavigationItem> NavigationItems { get; } =
[
    new()
    {
        Key = "home",
        Title = "主页",
        IconGlyph = "\uE80F",
        ToolTip = "进入主页"
    },
    new()
    {
        Key = "settings",
        Title = "设置",
        IconGlyph = "\uE713",
        ToolTip = "打开设置"
    }
];

public SUINavigationItem? SelectedNavigationItem { get; set; }
```

如果运行时需要从代码修改 `SelectedNavigationItem` 并刷新界面，该属性应通过 `INotifyPropertyChanged`、依赖属性或宿主项目已有的 MVVM 属性机制实现通知。

### 固定在底部的导航入口

将帮助、设置等入口放入 `FooterItemsSource`。默认模板把它们固定在侧栏底部，上方 `ItemsSource` 独立滚动；底部项目过多时也会在自己的区域内滚动。未设置或集合为空时，底部区域不占空间。

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    FooterItemsSource="{Binding FooterNavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}">
    <ContentControl Content="{Binding CurrentPage}" />
</suiNav:SUINavigationView>
```

宿主 ViewModel 可以分别准备两组集合：

```csharp
public ObservableCollection<SUINavigationItem> NavigationItems { get; } =
[
    new() { Key = "home", Title = "主页", IconGlyph = "\uE80F" },
    new() { Key = "tools", Title = "工具", IconGlyph = "\uE90F" }
];

public ObservableCollection<SUINavigationItem> FooterNavigationItems { get; } =
[
    new() { Key = "help", Title = "帮助", IconGlyph = "\uE897" },
    new() { Key = "settings", Title = "设置", IconGlyph = "\uE713" }
];
```

两组共用 `SelectedItem`、`SelectionChanged`、`ItemTemplate`、`ItemContainerStyle` 和尺寸属性；上下分组切换时只触发一次控件的选中事件，不会先回报空选中。默认双向绑定同样适用于底部入口，代码也可以直接把 `SelectedItem` 设置成底部集合中的项目。两组中的项目与 `Key` 应保持唯一，不要把同一个项目同时放入两组。

`Tab` 可以在上下列表之间移动焦点，方向键在当前组内切换。底部项目同样支持 `IsVisible`、`IsEnabled` 和属性变更通知。隐藏或禁用当前项目后需要切换到哪个页面，由宿主决定；Gallery 示例会主动回到总览。

### 将导航 Key 映射到页面

建议由宿主应用维护页面工厂，并按 `Key` 缓存页面实例：

```csharp
private readonly Dictionary<string, Func<UserControl>> _pageFactories = new()
{
    ["home"] = static () => new HomePageView(),
    ["settings"] = static () => new SettingsPageView()
};

private readonly Dictionary<string, UserControl> _pageCache = [];

private void NavigationRoot_SelectionChanged(object sender, SelectionChangedEventArgs e)
{
    if (NavigationRoot.SelectedItem is not SUINavigationItem item ||
        !_pageFactories.TryGetValue(item.Key, out Func<UserControl>? factory))
    {
        PageContent.Content = null;
        return;
    }

    if (!_pageCache.TryGetValue(item.Key, out UserControl? page))
    {
        page = factory();
        _pageCache[item.Key] = page;
    }

    PageContent.Content = page;
}
```

对应的 XAML 可以监听控件冒泡的 `SelectionChanged` 事件：

```xml
<suiNav:SUINavigationView
    x:Name="NavigationRoot"
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}"
    SelectionChanged="NavigationRoot_SelectionChanged">
    <ContentControl x:Name="PageContent" />
</suiNav:SUINavigationView>
```

### `SUINavigationView` 属性

| 属性/事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemsSource` | `IEnumerable?` | `null` | 上方导航项目集合，也可以使用自定义数据模型。 |
| `FooterItemsSource` | `IEnumerable?` | `null` | 固定在侧栏底部的导航项目集合，与上方共用选中状态、模板和样式。 |
| `SelectedItem` | `object?` | `null` | 当前选中项目，可来自上方或底部集合，默认双向绑定。 |
| `ItemTemplate` | `DataTemplate?` | 内置模板 | 自定义导航项的显示内容。 |

尺寸配置示例：

```xml
<suiNav:SUINavigationView

    PaneWidth="64"
    IconSize="20"

    LabelFontSize="12"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}" />
```

### `SUINavigationItem` 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Key` | `string` | 空字符串 | 项目唯一标识，用于页面路由或页面缓存。 |
| `Title` | `string` | 空字符串 | 导航标题。 |
| `IconGlyph` | `string` | 空字符串 | `Segoe Fluent Icons` 字体字符。 |
| `ToolTip` | `string?` | `null` | 鼠标停留时的提示文字。 |
| `BadgeText` | `string?` | `null` | 横向布局下显示在右侧的简短角标文字（为空时自动隐藏）。 |
| `BadgeVariant` | `BadgeVariant` | `Neutral` | 右侧角标的语义颜色。 |
| `IsEnabled` | `bool` | `true` | 是否允许选择该项目。 |
| `IsVisible` | `bool` | `true` | 是否显示该项目。 |

`SUINavigationItem` 实现了 `INotifyPropertyChanged`，运行时修改标题、图标、启用状态或显示状态会刷新界面。

### 横向二级导航（`Horizontal` 模式）

设置页、工具工作台左侧的二级菜单常需要「图标 + 标题 + 右侧角标 + 左侧选中指示条」的宽栏样式。只需将 `PaneLayout` 设为 `Horizontal`（位于 `SUI.Navigation.NavigationPaneLayout`），无需手写 `ItemTemplate` 与 `ControlTemplate`：

- 自动应用宽栏默认参数：`PaneWidth="200"`、`ItemHeight="36"`、`IconSize="16"`、`LabelFontSize="13"`（均可由局部属性覆盖）；
- 选中项左侧自动显示 3px `Accent` 圆角指示条；
- 当 `SUINavigationItem.BadgeText` 非空时，右侧自动渲染对应 `BadgeVariant` 的 `SUIBadge`，为空时自动折叠；如果传入自定义数据模型未包含 `BadgeText` 也不会引发绑定报错。

```xml
<suiNav:SUINavigationView
    PaneLayout="Horizontal"
    PaneWidth="190"
    ItemsSource="{Binding SettingsCategories}"
    SelectedItem="{Binding SelectedCategory, Mode=TwoWay}">
    <ContentControl Content="{Binding CurrentCategoryView}" />
</suiNav:SUINavigationView>
```

```csharp
public ObservableCollection<SUINavigationItem> SettingsCategories { get; } =
[
    new() { Key = "general", Title = "常规设置", IconGlyph = "\uE713" },
    new() { Key = "logs", Title = "日志占用", IconGlyph = "\uE8B7", BadgeText = "128 MB", BadgeVariant = BadgeVariant.Info },
    new() { Key = "experimental", Title = "实验特性", IconGlyph = "\uE90F", BadgeText = "占位", BadgeVariant = BadgeVariant.Warning },
];
```

### 自定义项目模板

`ItemsSource` 不强制必须使用 `SUINavigationItem`。如果导航数据提供图片或其他图标来源，可以完全替换默认模板：

```xml
<suiNav:SUINavigationView.ItemTemplate>
    <DataTemplate>
        <StackPanel VerticalAlignment="Center">
            <Image
                Width="18"
                Height="18"
                HorizontalAlignment="Center"
                Source="{Binding IconSource}" />
            <TextBlock
                Margin="0,2,0,0"
                HorizontalAlignment="Center"
                Text="{Binding Title}" />
        </StackPanel>
    </DataTemplate>
</suiNav:SUINavigationView.ItemTemplate>
```

### 导航使用建议

1. `Key` 在同一个导航控件的上下两组中保持唯一，并与宿主应用的页面路由表一致。
2. 默认图标依赖 Windows 的 `Segoe Fluent Icons` 字体；需要图片或自定义矢量图时使用 `ItemTemplate`。
3. 建议为 `SelectedItem` 设置初始值，避免程序启动时右侧内容为空。
4. 如果不需要前进/后退历史，建议使用 `ContentControl`，不必使用 `Frame`。

## 主题令牌

### 主题资源文件分工

> 注：`Themes/Metrics.xaml` 的独立拆分及下拉紧凑令牌（`SUI.Space.ComboBoxItemPadding`、`SUI.Control.ComboBoxItemMinHeight`）提交于 `v0.0.9` 之后（提交 `cad9212`）；在 NuGet `0.0.9` 包中，尺寸与字号令牌仍合并在 `Themes/Colors.xaml` 中，且尚未包含上述下拉紧凑令牌。

`Themes/Colors.xaml` 仅保存颜色和画刷，`Themes/Metrics.xaml` 保存字体、字号、高度、边框厚度、圆角与间距。资源键名保持不变；自行加载单个样式字典时，库内已同时合并两个基础字典。宿主手动组合基础资源时，先加载 Colors、再加载 Metrics、最后加载控件样式。直接只加载 Colors 不再提供尺寸资源。

下拉列表项内边距资源 `SUI.Space.ComboBoxItemPadding` 默认是 `6,0`（左、右各 6，上、下为 0），与输入框内边距分开管理。下拉项最小高度资源 `SUI.Control.ComboBoxItemMinHeight` 默认为 28，独立于输入框的默认高度 32；文字垂直居中，内容较高时仍可撑开。

## 原生控件样式

以下原生控件样式由 `SUIStyles.xaml` 统一加载。其中 `Switch` 和 `GridSplitter` 需要显式指定样式，其余按下文说明使用隐式样式。交互控件按适用场景提供悬停、按下、键盘焦点和禁用反馈，具体状态以对应控件实现为准。

### Button 与 ToggleButton

默认按钮：`Surface` 底、1px 边框、圆角 4、最小高度 32，内边距 `12,0`。`ToggleButton` 选中时显示 `Selected` 底和强调色边框。

```xml
<Button Content="普通按钮" />
<Button Content="保存" Style="{StaticResource SUI.Button.Primary}" />
<Button Content="执行升级" Style="{StaticResource SUI.Button.Success}" />
<Button Content="取消" Style="{StaticResource SUI.Button.Ghost}" />
<Button Content="删除" Style="{StaticResource SUI.Button.Danger}" />
<Button Content="读取" Style="{StaticResource SUI.Button.Compact}" />
<Button Style="{StaticResource SUI.Button.Icon}" ToolTip="刷新">
    <TextBlock FontFamily="{StaticResource SUI.Font.Icon}" Text="&#xE72C;" />
</Button>
<ToggleButton Content="开关按钮" IsChecked="True" />
```

| 样式键 | 外观 | 适用场景 |
| --- | --- | --- |
| 无（隐式） | 白底灰边框 | 普通操作。 |
| `SUI.Button.Primary` | 强调色底、白字、无边框 | 页面主要操作，一个区域建议只放一个。 |
| `SUI.Button.Success` | 语义绿底、白字、无边框 | 升级启动、验证通过等确认性主操作。 |
| `SUI.Button.Ghost` | 透明底无边框，悬停才显示底色 | 取消、工具栏等次要操作。 |
| `SUI.Button.Danger` | 红底白字 | 删除等不可恢复操作。 |
| `SUI.Button.Compact` / `Primary.Compact` / `Success.Compact` / `Ghost.Compact` / `Danger.Compact` | 28px 高、`8,0` 内边距 | 与 `SUI.TextBox.Compact` 对齐的高密度表单行尾或工具栏按钮。 |
| `SUI.Button.Icon` / `Icon.Compact` / `Icon.Ghost` / `Icon.Ghost.Compact` | 32×32 或 28×28 正方形纯图标按钮 | 工具栏、行尾刷新按钮、表格行内操作图标。 |
| `SUI.ToggleButton.Pill` | 胶囊圆角、28px 高，选中时 `Selected` 底 + `Accent` 边框与文字 | 多条件标签筛选、状态过滤药丸。 |

### TextBox 与 PasswordBox

`Surface` 底、1px 边框、圆角 4，文字垂直居中。悬停时边框变深；获得焦点时底边加粗为 2px 强调色；`IsReadOnly` 时底色为 `SurfaceAlt`；选区使用强调色。`AcceptsReturn="True"` 的多行输入框会自动使用更大的上下内边距。

```xml
<TextBox
    sui:TextBoxAssist.PlaceholderText="输入设备名称或关键词..."
    Text="{Binding Name, UpdateSourceTrigger=PropertyChanged}" />
<PasswordBox sui:TextBoxAssist.PlaceholderText="输入访问密钥" />
<TextBox AcceptsReturn="True" Height="96" TextWrapping="Wrap" />

<!-- 紧凑参数网格（高度 28、左右内边距 6，避免直接设 Height="28" 时与默认 MinHeight=32 冲突） -->
<TextBox Style="{StaticResource SUI.TextBox.Compact}" sui:TextBoxAssist.PlaceholderText="寄存器地址" />
<PasswordBox Style="{StaticResource SUI.PasswordBox.Compact}" />
```

- **占位提示**：通过附加属性 `sui:TextBoxAssist.PlaceholderText`（`xmlns:sui="clr-namespace:SUI;assembly=SUI"`）为 `TextBox`、`PasswordBox` 及 `DatePicker` 设置为空时的占位提示，无需外层叠放 `Grid`。
- **紧凑变体**：`SUI.TextBox.Compact` 与 `SUI.PasswordBox.Compact` 将 `MinHeight` 设为 `SUI.Control.Height.Compact`（28）、`Padding` 设为 `SUI.Space.TextBox.Padding.Compact`（`6,0`），适合高密度参数表格。
- **数据校验**：绑定校验失败（`Validation.HasError`）时，边框变红，并去掉系统默认的红色外框；把鼠标放在输入框上会通过 ToolTip 显示错误信息。校验规则（`ValidationRules`、`INotifyDataErrorInfo` 或 `IDataErrorInfo`）由你的绑定提供。

### ComboBox

外观与 TextBox 一致，右侧是矢量下拉箭头，下拉面板带圆角和轻阴影。同时支持不可编辑和 `IsEditable="True"` 的可编辑模式。

```xml
<ComboBox SelectedIndex="0" MaxDropDownHeight="200">
    <ComboBoxItem Content="COM1" />
    <ComboBoxItem Content="COM2" />
</ComboBox>

<ComboBox IsEditable="True" ItemsSource="{Binding BaudRates}" Text="{Binding BaudRate}" />
```

普通模式点击框内任意位置即可展开；可编辑模式仅点击右侧按钮展开，输入区域仍可自由输入。在可编辑框的输入区域滚动鼠标滚轮可逐项切换可选项，无需先聚焦：向上选择上一项，向下选择下一项，跳过禁用项，到首尾停止；自定义文本尚未匹配选项时，向下从第一项、向上从最后一项开始。下拉面板展开后，滚轮保留列表滚动行为。此行为由隐式样式启用，可通过 `sui:ComboBoxAssist.EnableEditableMouseWheel="False"` 关闭（`sui` 指向 `clr-namespace:SUI;assembly=SUI`）。

用 `MaxDropDownHeight` 限制下拉面板高度，超出后出现细滚动条。支持方向键切换、Esc 关闭，并在绑定触发 `Validation.HasError` 时呈现红色边框、红色聚焦底线与错误 `ToolTip`（同时屏蔽系统默认红框）。高密度参数网格可使用 `SUI.ComboBox.Compact`（最小高度 28、左右内边距 6、下拉按钮宽 28）与 `SUI.TextBox.Compact` 对齐。

### CheckBox 与 RadioButton

18×18 的方框（CheckBox 圆角 4，RadioButton 为圆形）。选中后为强调色底，CheckBox 显示白色对勾，RadioButton 显示白色圆点；`IsThreeState="True"` 的不确定态显示白色短横。

```xml
<CheckBox Content="记住我" IsChecked="True" />
<CheckBox Content="全选" IsThreeState="True" IsChecked="{x:Null}" />
<RadioButton Content="选项 1" GroupName="g" IsChecked="True" />
<RadioButton Content="选项 2" GroupName="g" />
```

键盘 Space 可切换。

若需要分栏筛选药丸（单选互斥），可对 `RadioButton` 指定显式样式 `SUI.RadioButton.Pill`（高 28、胶囊圆角、选中态 `Selected` 底 + `Accent` 边框与文字），并可直接配合 `EqualityConverter` 双向绑定枚举或字符串属性：

```xml
<StackPanel Orientation="Horizontal">
    <RadioButton Content="全部" GroupName="Filter" Style="{StaticResource SUI.RadioButton.Pill}"
                 IsChecked="{Binding Category, Converter={x:Static conv:EqualityConverter.Instance}, ConverterParameter=All}" />
    <RadioButton Content="纯本地" GroupName="Filter" Margin="8,0,0,0" Style="{StaticResource SUI.RadioButton.Pill}"
                 IsChecked="{Binding Category, Converter={x:Static conv:EqualityConverter.Instance}, ConverterParameter=Local}" />
</StackPanel>
```

### Switch 开关

`SwitchCheckBoxStyle` 把 `CheckBox` 显示为 40×20 的胶囊开关，需要显式指定样式（别名 `SUI.Switch`）。它与普通 `CheckBox` 样式互不影响。`IsChecked` 为 `null` 时按“关闭”显示。

```xml
<CheckBox Content="启用通知" IsChecked="{Binding NotifyEnabled}" Style="{StaticResource SwitchCheckBoxStyle}" />
```

### TabControl

`TabItem.HorizontalContentAlignment` 和 `VerticalContentAlignment` 默认均为 `Stretch`，页面内容填充可用内容区；标题独立居中（包括自定义图标标题）。可在单个 `TabItem` 上显式设为 `Center` 等值控制页面内容对齐，公开 WPF 属性保持兼容。这两个属性不再用于调整标题位置。

WPF 在更新选中页时会将这两个属性复制到 `PART_SelectedContentHost`，因此只给 `DataGrid` 或内部 `Grid` 设置 Stretch 不能修复上层宿主居中的问题。运行时更改已选中 TabItem 的内容对齐后，可重新选择该页以应用 WPF 的选中内容更新流程；SUI 未增加额外的即时同步行为。

填充型布局应由外层 Grid 等提供有限可用空间，不要放在垂直 StackPanel 中期待星号行分配剩余高度：

```xml
<TabControl>
    <TabItem Header="多条发送">
        <Grid Margin="12">
            <Grid.RowDefinitions>
                <RowDefinition Height="*" />
                <RowDefinition Height="Auto" />
            </Grid.RowDefinitions>
            <DataGrid ItemsSource="{Binding Commands}" AutoGenerateColumns="True" />
            <Button Grid.Row="1" Margin="0,12,0,0" Content="发送所选" />
        </Grid>
    </TabItem>
    <TabItem Header="居中内容" HorizontalContentAlignment="Center" VerticalContentAlignment="Center">
        <TextBlock Text="居中显示" />
    </TabItem>
</TabControl>
```

`Commands` 由宿主提供。Gallery「容器与反馈」提供表格、普通 Grid、简单文本及显式 Center 的实际 WPF 展示；网页代码片段不是 WPF 渲染效果证明。

顶部标签页。选中标签文字为 `Text` 色并带 2px 强调色下划线，未选中为 `TextSecondary`；内容区只有顶部一条分隔线。仅保证 `TabStripPlacement="Top"`；其他方向不会崩溃，但不保证外观。

```xml
<TabControl>
    <TabItem Header="常规"><TextBlock Text="常规内容" /></TabItem>
    <TabItem Header="高级"><TextBlock Text="高级内容" /></TabItem>
</TabControl>
```

**可关闭文档页与横向滚动溢出（`TabControlAssist`）**：

通过附加属性 `sui:TabControlAssist` 可为多文档 / 多工具页场景启用内置关闭按钮与单行横向滚动：

```xml
<TabControl
    sui:TabControlAssist.IsClosable="True"
    sui:TabControlAssist.IsHeaderScrollable="True"
    sui:TabControlAssist.CloseCommand="{Binding CloseTabCommand}">
    <!-- 单个标签可显式设为 False 保持常驻 -->
    <TabItem Header="应用中心" sui:TabControlAssist.IsClosable="False" />
    <TabItem Header="串口监视器" />
</TabControl>
```

| 附加属性 / 事件 / 命令 | 作用对象 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `TabControlAssist.IsClosable` | `TabControl` / `TabItem` | `false` | 开启标签右侧 `×` 关闭按钮；支持在标签头配对中键点击与聚焦时按 `Ctrl+F4`。在 `TabItem` 上设置可覆盖父级 `TabControl`。 |
| `TabControlAssist.CloseCommand` / `CloseCommandParameter` | `TabControl` / `TabItem` | `null` | 关闭时执行的 MVVM 命令（兼容 `RoutedCommand` 的 `CanExecute` 检查，并会忽略传入 `CloseTabCommand` 本身以免递归）；未设参数时默认传入对应数据项。未设置命令且未在 `CloseRequested` 中拦截时，自动从 `Items` 或可写 `ItemsSource` 中移除。 |
| `TabControlAssist.CloseRequested` | `TabItem`（冒泡路由事件） | — | 关闭前触发（`TabCloseRequestedEventArgs`）；将 `e.Handled = true` 可取消关闭或自行弹出未保存确认。 |
| `TabControlAssist.IsHeaderScrollable` | `TabControl` | `false` | 设为 `true` 后标题栏改为单行横向滚动（支持鼠标滚轮）；超出可见宽度时自动显示左右滚动按钮与「全部标签」下拉菜单（提取复合标题文本时会自动过滤图标字体的私用区字符）。 |
| `TabControlAssist.HasHeaderOverflow` | `TabControl`（只读） | `false` | 横向滚动模式下标题栏当前是否发生溢出。 |

### GroupBox、Expander 与卡片容器

`GroupBox` 默认提供隐式样式，渲染为 `Surface` 底、1px `Border` 边框、`SUI.Radius.Panel` 圆角与顶部标题分隔栏的分组卡片；当 `Header` 为 `null` 或空字符串时标题栏自动折叠。不需要标题栏的轻量表单/信息卡片可直接对 `Border` 使用 `SUI.Border.Card`。

`Expander` 默认提供隐式样式，渲染为带 Fluent 展开箭头与展开分隔线的可折叠卡片容器（支持 `Down`/`Up`/`Left`/`Right` 四个展开方向）；若需要嵌套在已有 `GroupBox` 或 `SUI.Border.Card` 内部，可使用 `SUI.Expander.Plain` 去掉外层背景与边框。

```xml
<GroupBox Header="串口连接参数">
    <StackPanel>
        <TextBox Style="{StaticResource SUI.TextBox.Compact}" sui:TextBoxAssist.PlaceholderText="超时时间 (ms)" />
    </StackPanel>
</GroupBox>

<Expander Header="高级参数" IsExpanded="False">
    <TextBlock Text="重发超时、重试次数与运行参数等次要配置。" />
</Expander>

<Border Style="{StaticResource SUI.Border.Card}">
    <Expander Header="嵌套在卡片中的折叠分组" Style="{StaticResource SUI.Expander.Plain}">
        <TextBlock Text="无外框双重边界" />
    </Expander>
</Border>
```

### DatePicker 与 Calendar

原生 `DatePicker`、`DatePickerTextBox` 与 `Calendar` 均已提供 SUI 隐式样式：输入框视觉与 `TextBox` 对齐（高 32、圆角 4、聚焦 2px 强调色底边），支持通过 `sui:TextBoxAssist.PlaceholderText` 自定义空值提示（默认“选择日期”）；弹出日历面板使用统一圆角、今日边框标记、强调色选中态与禁用/不可选日期划线。支持 `Style="{StaticResource SUI.DatePicker.Compact}"`（28px 高度）与 `Validation.HasError` 红色错误边框及 `ToolTip` 提示。

```xml
<DatePicker Width="180" sui:TextBoxAssist.PlaceholderText="选择开始日期" SelectedDate="{Binding StartDate}" />
<DatePicker Width="160" Style="{StaticResource SUI.DatePicker.Compact}" SelectedDate="{Binding StartDate}" />
<Calendar SelectedDate="{Binding SelectedDate}" />
```

### ListBox

`Surface` 底、1px 边框、圆角 4，条目最小高度 32。选中项为 `Selected` 底，窗口失去焦点后依然保持选中底色，`SelectionMode="Extended"` 多选时可清楚辨认。

```xml
<ListBox ItemsSource="{Binding Items}" SelectedItem="{Binding Current}" SelectionMode="Extended" />
```

若需要用于设置页或二级分类菜单（透明底、无外框、内边距紧凑、带左侧 3px `Accent` 选中指示条），可直接使用 `SUI.ListBox.Navigation`（容器样式为 `SUI.ListBoxItem.Navigation`），并按需配合 `SUIBadge` 定义内容模板：

```xml
<ListBox Style="{StaticResource SUI.ListBox.Navigation}"
         ItemsSource="{Binding Categories}"
         SelectedItem="{Binding CurrentCategory}">
    <ListBox.ItemTemplate>
        <DataTemplate>
            <Grid>
                <Grid.ColumnDefinitions>
                    <ColumnDefinition Width="Auto" />
                    <ColumnDefinition Width="*" />
                    <ColumnDefinition Width="Auto" />
                </Grid.ColumnDefinitions>
                <TextBlock Text="{Binding Icon}" FontFamily="{StaticResource SUI.Font.Icon}" Margin="0,0,10,0" VerticalAlignment="Center" />
                <TextBlock Grid.Column="1" Text="{Binding Name}" VerticalAlignment="Center" />
                <sui:SUIBadge Grid.Column="2" Content="{Binding Badge}" Variant="Warning" Padding="6,1" />
            </Grid>
        </DataTemplate>
    </ListBox.ItemTemplate>
</ListBox>
```

`SUINavigationView` 内部的 ListBox 使用自己的显式样式，不受此隐式样式影响。

### ScrollBar 与 ScrollViewer

滚动条宽/高为 10，透明轨道保留完整的拖动命中区域；滑块以居中的细圆角条显示，悬停或拖动时加宽并加深。垂直和水平都支持，保留鼠标滚轮与翻页命令。`DataGrid`、`ListBox`、多行 `TextBox`、`ComboBox` 下拉里的滚动条外观一致。

```xml
<ScrollViewer HorizontalScrollBarVisibility="Auto" VerticalScrollBarVisibility="Auto">
    <!-- 内容 -->
```

```xml
<Button Content="提示" ToolTip="这是一段提示文字" />
```

### ProgressBar

```xml
<ProgressBar Value="{Binding Progress}" Maximum="100" />
```

### DataGrid

隐式样式已覆盖 `DataGrid`，也可使用显式键 `CommonDataGridStyle`。表头为 `SurfaceAlt` 底，并延伸到右侧垂直滚动条槽位，使表格顶边连续铺满；行有交替底色；悬停为 `Hover` 底；选中行为 `Selected` 底，窗口失焦后依然保持；单元格编辑态（`IsEditing`）自动呈强调色边框；表头支持排序箭头（升序/降序小三角）。保持了行虚拟化，大数据量滚动流畅，不要在行或单元格里使用 `Effect`。

```xml
<DataGrid ItemsSource="{Binding Rows}"

    <DataGrid.Columns>
        <DataGridCheckBoxColumn Header="启用"
                                Width="48"
                                Binding="{Binding Enabled}"
                                ElementStyle="{StaticResource SUI.DataGrid.CheckBox}"
                                EditingElementStyle="{StaticResource SUI.DataGrid.CheckBox}" />
        <DataGridTextColumn Header="名称"
                            Binding="{Binding Name}"
                            EditingElementStyle="{StaticResource SUI.DataGrid.TextBox}"
                            Width="*" />
    </DataGrid.Columns>
</DataGrid>
```

### GridSplitter

1px 细分隔线，悬停和拖动时变为强调色，线宽不变，不会引起布局抖动。透明命中区由 `Width`/`Height` 决定，建议设为 8 以上便于拖动。

```xml
<!-- 竖向，用于左右分栏 -->
<GridSplitter Grid.Column="1" Width="8" HorizontalAlignment="Center"
              Style="{StaticResource CustomGridSplitterStyle}" />

<!-- 横向，用于上下分区 -->
<GridSplitter Grid.Row="1" Height="8"
              Style="{StaticResource SUI.GridSplitter.Horizontal}" />
```

两种样式都预设 `ShowsPreview="True"`。拖动时显示强调色细线与中央短握柄作为位置预览，松开鼠标后再调整布局；横向与竖向样式分别提供对应的预览样式。

## `TreeStyles` 树样式

`TreeStyles` 为 WPF 原生 `TreeViewItem` 提供展开箭头、文件夹和叶子节点图标、层级引导线、悬停、选中、键盘焦点和禁用状态。合并 `SUIStyles.xaml` 后，普通 `TreeView` 的条目会自动使用该样式；需要显式指定时仍可使用 `SUITreeViewItemStyle`。

节点模型和显示模板由宿主应用决定。SUI 不定义 `ItemsSource` 的数据字段，也不提供固定的节点 `DataTemplate`。

### 基本用法

宿主应用合并 `/SUI;component/SUIStyles.xaml` 后，为自己的节点模型定义层级模板。以下示例使用 `Name` 和 `Children` 字段：

```xml
<TreeView
    xmlns:sui="clr-namespace:SUI;assembly=SUI"
    ItemsSource="{Binding Nodes}"
    sui:TreeStyles.ItemMinHeight="36"
    sui:TreeStyles.ItemCornerRadius="8"
    sui:TreeStyles.IconSize="17"
    sui:TreeStyles.ItemFontSize="13">
    <TreeView.ItemTemplate>
        <HierarchicalDataTemplate ItemsSource="{Binding Children}">
            <TextBlock Text="{Binding Name}" />
        </HierarchicalDataTemplate>
    </TreeView.ItemTemplate>
</TreeView>
```

如果需要显式复用带 key 的容器样式，可设置 `ItemContainerStyle="{StaticResource SUITreeViewItemStyle}"`。宿主也可以在自己的层级模板中显示额外字段，例如 OI 编号，并使用 `SUI.Brush.TextSecondary` 设置次要文字颜色。

### 可配置布局属性

以下四个附加属性只控制布局，设置在 `TreeView` 上后会传递给内部的 `TreeViewItem`：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemMinHeight` | `double` | `36` | 节点最小高度。 |
| `ItemCornerRadius` | `CornerRadius` | `8` | 节点背景圆角。 |
| `IconSize` | `double` | `17` | 文件夹和叶子图标尺寸。 |
| `ItemFontSize` | `double` | `13` | 节点标题字号。 |

悬停、选中、焦点、禁用状态和图标颜色由 `Colors.xaml` 统一提供，不需要在 `TreeView` 上配置颜色附加属性。

## 转换器

命名空间：

```csharp
using SUI.Converters;
```

| 类型 | 用途 |
| --- | --- |
| `BadgeCornerRadiusConverter` | 徽标模板使用：将实际高度转换为高度一半的 CornerRadius；反向转换返回 Binding.DoNothing。 |
| BoolToVisibilityConverter | `true` 转为 `Visible`，其他值转为 `Collapsed`。反向转换时只有 `Visible` 为 `true`。 |
| `ColorStringToBrushConverter` | 将 `#4C79FF` 等颜色字符串转换为 `SolidColorBrush`；无效值使用默认蓝色。 |
| `EqualityConverter` | 同时实现 `IValueConverter` 与 `IMultiValueConverter`：支持单值绑定 + `ConverterParameter`（双向绑定 `true` 时支持 `ConvertBack`，兼容 `Enum`、数值与基础类型及字符串参数）及双值 `MultiBinding` 比较；可直接使用静态实例 `EqualityConverter.Instance`。 |

单值绑定示例（常用于 `SUI.RadioButton.Pill` 绑定枚举、数值或字符串）：

```xml
<RadioButton
    Content="十六进制"
    Style="{StaticResource SUI.RadioButton.Pill}"
    IsChecked="{Binding DisplayMode, Converter={x:Static conv:EqualityConverter.Instance}, ConverterParameter=Hex}" />
```

## `FileUpload` 与 `TimePicker`

### `FileUpload` 本地文件选择与拖放

`FileUpload` 封装了 Win32 `OpenFileDialog` 扩展名过滤、单选/多选与资源管理器拖放校验，并内置已选文件列表、逐项移除与一键清空，无需在各页面重复编写文件对话框样板代码。除了默认的拖放卡片形态，还可通过 `IsCompact="True"` 或 `Style="{StaticResource SUI.FileUpload.Compact}"` 切换为紧凑单行路径模式（高度贴近 `32px`，保留拖放高亮、清空图标按钮、浏览按钮及 `Validation.HasError` 校验边框）。

```xml
<!-- 标准拖放卡片模式 -->
<sui:FileUpload
    Title="选择固件或配置文件"
    Description="支持 .bin、.txt 文件；点击按钮或直接拖放到此区域"
    Filter="固件与文本 (*.bin;*.txt)|*.bin;*.txt|所有文件 (*.*)|*.*"
    SelectedFilePath="{Binding FirmwarePath}"
    FilesSelectedCommand="{Binding OnFilesPickedCommand}" />

<!-- 紧凑单行模式 -->
<sui:FileUpload
    IsCompact="True"
    Title="选择升级固件"
    PlaceholderText="选择或拖放固件文件..."
    Filter="固件文件 (*.bin;*.hex)|*.bin;*.hex|所有文件 (*.*)|*.*"
    SelectedFilePath="{Binding FirmwarePath}" />
```

| 属性 / 方法 / 事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Title` | `string` | `选择文件` | 区域主标题，同时用作文件对话框标题。 |
| `Description` | `string?` | 拖放提示 | 辅助说明，为空时自动折叠。 |
| `ButtonText` | `string` | `浏览文件` | 选择按钮文案。 |
| `Filter` | `string` | `所有文件 (*.*)\|*.*` | Win32 `OpenFileDialog` 格式过滤器。拖放时会按具体扩展名模式（含 `*.tar.gz` 等多段扩展名）校验；仅当首组过滤器本身为 `*.*` / `*` 时放开拖放校验，后续分组中的兜底 `*.*` 不会导致限制失效。 |
| `InitialDirectory` | `string?` | `null` | 对话框初始目录（可选）。 |
| `AllowMultiple` | `bool` | `false` | 是否允许选择或拖入多个文件。 |
| `AllowDropFiles` | `bool` | `true` | 是否允许从资源管理器拖放文件；拖入有效文件时高亮边框。 |
| `IsCompact` | `bool` | `false` | 是否启用紧凑单行路径模式（也可通过 `SUI.FileUpload.Compact` 样式开启）。 |
| `ShowFullPath` | `bool` | `false` | 紧凑单行模式下是否直接显示完整路径；默认 `false`（框内仅显示文件名避免窄列截断，完整路径通过 `ToolTip` 展示）。 |
| `PlaceholderText` | `string?` | `点击浏览或拖放文件...` | 紧凑单行模式下尚未选择文件时的占位提示。 |
| `HasFiles` / `DisplayCompactText` / `DisplayFilePath` | `bool` / `string`（只读） | `false` / 空字符串 | 当前是否已选文件、紧凑模式下展示的文本摘要以及完整路径摘要。 |
| `SelectedFilePath` | `string?` | `null` | 当前选中的首个文件路径，默认双向绑定。 |
| `SelectedFiles` | `ObservableCollection<string>`（只读） | 空集合 | 当前已选中的全部文件路径列表。 |
| `FilesSelectedCommand` | `ICommand?` | `null` | 选择变化后执行的命令，参数为 `IReadOnlyList<string>`。 |
| `FilesSelected` | 路由事件 | — | 选择变化后触发（`FilesSelectedEventArgs`）。 |
| `Browse()` / `Clear()` | 方法 | — | 编程触发打开文件对话框或清空已选文件。 |

### `TimePicker` 时间选择器

`TimePicker` 提供与 `TextBox` / `DatePicker` 一致的外观，支持直接键入时间文本（`HH:mm` 或 `HH:mm:ss`，按 `Enter`、失焦或展开下拉前自动提交，`Esc` 撤销）以及点击右侧时钟图标展开/收起分栏下拉选择（时 / 分 / 可选秒），修改某一栏时会保留未在步长列表中的精确分/秒数值，禁用或只读时自动收起下拉，并内置「此刻」「清除」「确定」快捷操作。支持 `Style="{StaticResource SUI.TimePicker.Compact}"`（28px 高度）与 `Validation.HasError` 红色错误边框及 `ToolTip` 提示。

```xml
<sui:TimePicker Width="160" MinuteIncrement="5" PlaceholderText="选择执行时间" SelectedTime="{Binding ScheduleTime}" />
<sui:TimePicker Width="170" ShowSeconds="True" SelectedTime="09:30:15" />
<sui:TimePicker Width="140" Style="{StaticResource SUI.TimePicker.Compact}" ShowSeconds="True" SelectedTime="{Binding StartTime}" />
```

| 属性 / 事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `SelectedTime` | `TimeSpan?` | `null` | 选中时间（`00:00:00`–`23:59:59`），默认双向绑定。 |
| `ShowSeconds` | `bool` | `false` | 是否显示并选择秒数。 |
| `MinuteIncrement` / `SecondIncrement` | `int` | `1` | 下拉分钟/秒数列表步长（`1`–`60`）。 |
| `PlaceholderText` | `string?` | `选择时间` | 输入框为空时的占位提示。 |
| `IsReadOnly` | `bool` | `false` | 只读状态，禁止编辑与展开下拉。 |
| `IsDropDownOpen` | `bool` | `false` | 控制时间选择下拉面板展开/收起，默认双向绑定。 |
| `SelectedTimeChanged` | 路由事件 | — | `SelectedTime` 变更时触发（`RoutedPropertyChangedEventArgs<TimeSpan?>`）。 |

## 构建与排查

### 构建命令

在仓库根目录执行：

```powershell
dotnet build SUI.slnx
```

解决方案包含 SUI 库与 `samples/SUI.Gallery` 展示应用。使用 `dotnet build SUI.slnx` 构建；运行 Gallery 可直接检查控件外观、状态和交互效果。

### 常见问题

**控件无法解析或 XAML 报命名空间错误**

确认宿主项目已经安装 `SUI` NuGet 包或添加本地项目引用，并检查命名空间是否分别使用 `SUI` 和 `SUI.Navigation`。使用 NuGet 时，先确认包还原成功，且安装版本包含所用的 API。

**导航控件没有默认样式**

确认 `Themes/Generic.xaml` 仍作为项目资源参与编译，并且宿主项目引用的是当前 SUI 程序集。

**图标显示为空**

使用 `IconGlyph` 时确认系统存在 `Segoe Fluent Icons` 字体；使用图片时确认 `ImageSource` 的资源路径和 Build Action 正确。

**样式资源找不到**

确认已经合并 `/SUI;component/SUIStyles.xaml`，并且资源键拼写与 `Styles/` 文件中的定义一致。

**引用 NuGet `0.0.9` 时提示找不到 `Metrics.xaml` 或 `SUIInfoBar` / `SUINumberBox` 等新控件**

`0.0.9` 对应提交 `52024e5`，尚未包含之后拆分的 `Themes/Metrics.xaml`、`SUIDialog` / `SUINumberBox` 及后续新增控件。遇到此类编译或资源异常时，请升级到 `0.1.1` 或参照本手册顶部的「版本能力对照」表改用最新主干源码的 `ProjectReference`。

**`SUI.Switch` 初始 `IsChecked="True"` 首帧显示为关闭态（`0.0.9` 及更早版本）**

`0.0.9` 及更早版本的 `SwitchCheckBoxStyle` 使用 `Trigger.EnterActions` 驱动动画，首次加载已勾选开关时会先渲染关闭态再播放 200ms 动画。当前主干源码已改为 `VisualStateManager`，首帧直接落位到开启态。
