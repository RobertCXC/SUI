## 接入项目

### 添加项目引用

在宿主 WPF 项目的 `.csproj` 中引用 SUI：

```xml
<ProjectReference Include="..\SUI\SUI.csproj" />
```

路径需要根据宿主项目和 SUI 的实际目录层级调整。

### 引用命名空间

普通控件位于 `SUI` 命名空间：

```xml
xmlns:sui="clr-namespace:SUI;assembly=SUI"
```

导航控件位于 `SUI.Navigation` 命名空间：

```xml
xmlns:suiNav="clr-namespace:SUI.Navigation;assembly=SUI"
```

### 合并公共样式

如果宿主应用需要使用 SUI 提供的 DataGrid、GridSplitter 和 SwitchCheckBox 样式，可以在 `App.xaml` 中合并：

```xml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="/SUI;component/SUIStyles.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

`SUINavigationView` 的默认样式位于 [`../Themes/Generic.xaml`](../Themes/Generic.xaml)，WPF 会通过默认样式键自动加载，不需要在应用中重复合并。

## `SUICard` 卡片控件

`SUICard` 是一个轻量卡片控件，适合展示应用入口、状态摘要或功能概览。它继承自 `UserControl`，通过依赖属性提供基本配置。

### 基本用法

```xml
<sui:SUICard
    Title="项目状态"
    Description="这是一个可复用的 WPF 卡片"
    IconText="S" />
```

### 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `IconSource` | `ImageSource?` | `null` | 图标图片。设置后会替换默认的文字图标。 |
| `Title` | `string` | `标题` | 卡片标题。 |
| `Description` | `string` | `略` | 卡片描述，支持换行。 |
| `IconText` | `string` | `S` | 没有 `IconSource` 时显示的占位文字。 |
| `IconColor` | `Brush` | `#4C79FF` | 默认文字图标的背景画刷。 |

### 数据绑定

所有上述属性都是依赖属性，可以直接绑定到 ViewModel：

```xml
<sui:SUICard
    Description="{Binding Description}"
    IconColor="{Binding AccentBrush}"
    IconSource="{Binding IconSource}"
    IconText="{Binding IconText}"
    Title="{Binding Title}" />
```

如果使用图片作为 `IconSource`，请确保图片格式和资源路径已被宿主 WPF 项目正确处理。SUI 不额外提供 SVG 渲染器。

## `SUINavigationView` 导航控件

`SUINavigationView` 是一个“图标在上、标题在下”的窄侧边导航壳。它只负责导航项目、选中状态和左右布局；右侧页面由宿主应用提供，因此不会反向依赖业务页面。

### 基本接入

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}">
    <ContentControl Content="{Binding CurrentPage}" />
</suiNav:SUINavigationView>
```

### 准备导航数据

最简单的方式是使用 `SUINavigationItem`：

```csharp
using System.Collections.ObjectModel;
using SUI.Navigation;

public ObservableCollection<SUINavigationItem> NavigationItems { get; } =
[
    new()
    {
        Key = "home",
        Title = "主页",
        IconGlyph = "\uE80F",
        ToolTip = "进入主页"
    },
    new()
    {
        Key = "settings",
        Title = "设置",
        IconGlyph = "\uE713",
        ToolTip = "打开设置"
    }
];

public SUINavigationItem? SelectedNavigationItem { get; set; }
```

如果运行时需要从代码修改 `SelectedNavigationItem` 并刷新界面，该属性应通过 `INotifyPropertyChanged`、依赖属性或宿主项目已有的 MVVM 属性机制实现通知。

### 将导航 Key 映射到页面

建议由宿主应用维护页面工厂，并按 `Key` 缓存页面实例：

```csharp
private readonly Dictionary<string, Func<UserControl>> _pageFactories = new()
{
    ["home"] = static () => new HomePageView(),
    ["settings"] = static () => new SettingsPageView()
};

private readonly Dictionary<string, UserControl> _pageCache = [];

private void NavigationRoot_SelectionChanged(object sender, SelectionChangedEventArgs e)
{
    if (NavigationRoot.SelectedItem is not SUINavigationItem item ||
        !_pageFactories.TryGetValue(item.Key, out Func<UserControl>? factory))
    {
        PageContent.Content = null;
        return;
    }

    if (!_pageCache.TryGetValue(item.Key, out UserControl? page))
    {
        page = factory();
        _pageCache[item.Key] = page;
    }

    PageContent.Content = page;
}
```

对应的 XAML 可以监听控件冒泡的 `SelectionChanged` 事件：

```xml
<suiNav:SUINavigationView
    x:Name="NavigationRoot"
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}"
    SelectionChanged="NavigationRoot_SelectionChanged">
    <ContentControl x:Name="PageContent" />
</suiNav:SUINavigationView>
```

### `SUINavigationView` 属性

| 属性/事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemsSource` | `IEnumerable?` | `null` | 导航项目集合，也可以使用自定义数据模型。 |
| `SelectedItem` | `object?` | `null` | 当前选中项目，默认双向绑定。 |
| `ItemTemplate` | `DataTemplate?` | 内置模板 | 自定义导航项的显示内容。 |
| `ItemContainerStyle` | `Style?` | 内置样式 | 自定义导航项容器的间距、圆角、悬停和选中效果。 |
| `PaneWidth` | `GridLength` | `56` | 左侧导航栏宽度。 |
| `IconSize` | `double` | `18` | 默认模板中的图标字号。 |
| `ItemHeight` | `double` | `54` | 每个导航项的高度。 |
| `LabelFontSize` | `double` | `11` | 默认模板中的标题字号。 |
| `SelectionChanged` | 路由事件 | — | 用户点击或代码改变选中项时触发。 |

尺寸配置示例：

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    PaneWidth="64"
    IconSize="20"
    ItemHeight="58"
    LabelFontSize="12"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}" />
```

### `SUINavigationItem` 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Key` | `string` | 空字符串 | 项目唯一标识，用于页面路由或页面缓存。 |
| `Title` | `string` | 空字符串 | 导航标题。 |
| `IconGlyph` | `string` | 空字符串 | `Segoe Fluent Icons` 字体字符。 |
| `ToolTip` | `string?` | `null` | 鼠标停留时的提示文字。 |
| `IsEnabled` | `bool` | `true` | 是否允许选择该项目。 |
| `IsVisible` | `bool` | `true` | 是否显示该项目。 |

`SUINavigationItem` 实现了 `INotifyPropertyChanged`，运行时修改标题、图标、启用状态或显示状态会刷新界面。

### 自定义项目模板

`ItemsSource` 不强制必须使用 `SUINavigationItem`。如果导航数据提供图片或其他图标来源，可以完全替换默认模板：

```xml
<suiNav:SUINavigationView.ItemTemplate>
    <DataTemplate>
        <StackPanel VerticalAlignment="Center">
            <Image
                Width="18"
                Height="18"
                HorizontalAlignment="Center"
                Source="{Binding IconSource}" />
            <TextBlock
                Margin="0,2,0,0"
                HorizontalAlignment="Center"
                Text="{Binding Title}" />
        </StackPanel>
    </DataTemplate>
</suiNav:SUINavigationView.ItemTemplate>
```

### 导航使用建议

1. `Key` 在同一个导航列表中保持唯一，并与宿主应用的页面路由表一致。
2. 默认图标依赖 Windows 的 `Segoe Fluent Icons` 字体；需要图片或自定义矢量图时使用 `ItemTemplate`。
3. 建议为 `SelectedItem` 设置初始值，避免程序启动时右侧内容为空。
4. 如果不需要前进/后退历史，建议使用 `ContentControl`，不必使用 `Frame`。

## 样式资源

### 总入口

[`SUIStyles.xaml`](../SUIStyles.xaml) 会合并以下资源：

- `CommonDataGridStyle`
- `CommonDataGridColumnHeaderStyle`
- `CommonDataGridCellStyle`
- `CustomGridSplitterStyle`
- `SwitchCheckBoxStyle`
- `SUITreeViewItemStyle`

使用示例：

```xml
<DataGrid Style="{StaticResource CommonDataGridStyle}" />
<GridSplitter Style="{StaticResource CustomGridSplitterStyle}" />
<CheckBox Style="{StaticResource SwitchCheckBoxStyle}" Content="启用" />
```

### `TreeStyles` 树样式

`TreeStyles` 为 WPF 原生 `TreeViewItem` 提供展开箭头、文件夹和叶子节点图标、层级引导线、悬停、选中、键盘焦点和禁用状态。合并 `SUIStyles.xaml` 后，普通 `TreeView` 的条目会自动使用该样式；需要显式指定时仍可使用 `SUITreeViewItemStyle`。

节点模型和显示模板由宿主应用决定。SUI 不定义 `ItemsSource` 的数据字段，也不提供固定的节点 `DataTemplate`。

#### 基本用法

宿主应用合并 `/SUI;component/SUIStyles.xaml` 后，为自己的节点模型定义层级模板。以下示例使用 `Name` 和 `Children` 字段：

```xml
<TreeView
    xmlns:sui="clr-namespace:SUI;assembly=SUI"
    ItemsSource="{Binding Nodes}"
    sui:TreeStyles.ItemMinHeight="36"
    sui:TreeStyles.ItemCornerRadius="8"
    sui:TreeStyles.IconSize="17"
    sui:TreeStyles.ItemFontSize="13">
    <TreeView.ItemTemplate>
        <HierarchicalDataTemplate ItemsSource="{Binding Children}">
            <TextBlock Text="{Binding Name}" />
        </HierarchicalDataTemplate>
    </TreeView.ItemTemplate>
</TreeView>
```

如果需要显式复用带 key 的容器样式，可设置 `ItemContainerStyle="{StaticResource SUITreeViewItemStyle}"`。宿主也可以在自己的层级模板中显示额外字段，例如 OI 编号，并使用 `SUI.Brush.TextSecondary` 设置次要文字颜色。

#### 可配置布局属性

以下四个附加属性只控制布局，设置在 `TreeView` 上后会传递给内部的 `TreeViewItem`：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemMinHeight` | `double` | `36` | 节点最小高度。 |
| `ItemCornerRadius` | `CornerRadius` | `8` | 节点背景圆角。 |
| `IconSize` | `double` | `17` | 文件夹和叶子图标尺寸。 |
| `ItemFontSize` | `double` | `13` | 节点标题字号。 |

悬停、选中、焦点、禁用状态和图标颜色由 `Colors.xaml` 统一提供，不需要在 `TreeView` 上配置颜色附加属性。

### 默认主题

导航控件默认主题和颜色资源位于 [`Themes/Generic.xaml`](../Themes/Generic.xaml)。局部属性、`ItemTemplate` 和 `ItemContainerStyle` 的设置优先于默认样式，不需要直接修改库内主题文件。

## 转换器

命名空间：

```csharp
using SUI.Converters;
```

| 类型 | 用途 |
| --- | --- |
| `BoolToVisibilityConverter` | `true` 转为 `Visible`，其他值转为 `Collapsed`。反向转换时只有 `Visible` 为 `true`。 |
| `ColorStringToBrushConverter` | 将 `#4C79FF` 等颜色字符串转换为 `SolidColorBrush`；无效值使用默认蓝色。 |
| `EqualityConverter` | 比较两个绑定值是否相等；可直接使用静态实例 `EqualityConverter.Instance`。 |

## `FileUpload` 与 `TimePicker`

这两个控件已经具备 WPF `UserControl` 的基础结构，可以直接放入 XAML：

```xml
<sui:FileUpload />
<sui:TimePicker />
```

当前版本主要用于搭建控件外壳和视觉占位：

- `FileUpload` 当前显示文件上传控件的基础提示，尚未封装完整的文件选择、校验和上传流程。
- `TimePicker` 当前显示时间选择的基础提示，尚未封装完整的时间选择 API。

实际项目接入前，请根据自己的交互需求补充或扩展对应的依赖属性、命令和事件。

## 构建与排查

### 构建命令

请使用项目约定的 .NET SDK 10.0.302：

```powershell
& 'C:\Program Files\dotnet\sdk\10.0.302\MSBuild.exe' .\SUI.csproj /t:Build /p:Configuration=Debug
```

不要使用未固定 SDK 版本的默认 `dotnet build`、`dotnet pack` 或 `dotnet test` 命令。

### 常见问题

**控件无法解析或 XAML 报命名空间错误**

确认宿主项目已经添加项目引用，并检查命名空间是否分别使用 `SUI` 和 `SUI.Navigation`。

**导航控件没有默认样式**

确认 `Themes/Generic.xaml` 仍作为项目资源参与编译，并且宿主项目引用的是当前 SUI 程序集。

**图标显示为空**

使用 `IconGlyph` 时确认系统存在 `Segoe Fluent Icons` 字体；使用图片时确认 `ImageSource` 的资源路径和 Build Action 正确。

**样式资源找不到**

确认已经合并 `/SUI;component/SUIStyles.xaml`，并且资源键拼写与 `Styles/` 文件中的定义一致。
