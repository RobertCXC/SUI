# SUI 使用手册

本文档对应当前仓库中的 SUI 实现，介绍项目接入方式、控件 API、样式资源和常见使用模式。

SUI 是供 Windows 桌面应用使用的 WPF 控件与样式库，目标框架是 `net48`、`net8.0-windows`、`net10.0-windows`。推荐通过 [NuGet 包 SUI](https://www.nuget.org/packages/SUI) 接入；需要修改库源码或联调时，也可以使用本地 `ProjectReference`。

以下 NuGet 示例以已发布的 `0.0.3` 版本为例。手册 API 按当前仓库源码编写；安装其他版本或使用尚未发布的功能时，请核对对应版本的源码和发布说明。

## 快速开始

### 环境要求

- 主要面向 Windows 10 / 11，宿主项目启用 WPF。
- 当前源码同时生成 `net48`、`net8.0-windows`、`net10.0-windows` 三个版本：分别供 .NET Framework 4.8 / 4.8.1、.NET 8 / 9、.NET 10 项目使用；现代 .NET 5～7 不在本次支持范围内。
- 编译仓库源码需要 .NET 10 SDK，以及 .NET Framework 4.8 目标包（Developer Pack / 引用程序集）。仓库明确使用 C# 12 编译；应用通过 NuGet 引用已编译的库时，无需因此升级其 C# 语言版本。
- 运行用户只需应用对应的运行时：Framework 应用使用 4.8 / 4.8.1，现代 WPF 应用使用对应的 .NET Desktop Runtime；不要求安装 SDK。自包含发布由宿主应用决定。

多目标能力对应当前源码及后续包含此改动的发布包，不代表下文示例中的已发布 `0.0.3` 包已经支持这些目标。

一次打包仍生成一个 SUI NuGet 包、使用同一个版本号，内部按目标框架存放三份 `SUI.dll`，NuGet 自动选取匹配版本。手动引用 DLL 时，请从 `bin/Release/<目标框架>/` 选取对应文件，不要混用。

### 1. 通过 NuGet 安装 SUI

在你的 WPF 项目 `.csproj` 所在目录执行：

```powershell
dotnet add package SUI --version 0.0.3
```

也可以在 Visual Studio 的“管理 NuGet 程序包”中搜索 `SUI`，确认作者为 `RobertCXC` 后安装。包地址：[nuget.org/packages/SUI](https://www.nuget.org/packages/SUI)。

NuGet 会添加包引用，并在还原、构建时自动引用包中的 `SUI.dll`。对应的项目配置如下（与上面的安装命令二选一）：

```xml
<ItemGroup>
    <PackageReference Include="SUI" Version="0.0.3" />
</ItemGroup>
```

接下来合并样式并使用控件即可；只有运行仓库 Gallery 或修改库源码时才需要克隆仓库。

### 2. 在 `App.xaml` 合并样式

把 `SUIStyles.xaml` 合并到应用级资源中。这样按钮、文本框、列表等原生 WPF 控件会自动采用 SUI 外观：

```xml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="/SUI;component/SUIStyles.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

### 3. 在页面中使用

将 `SUI` 命名空间映射到 XAML 前缀，然后像使用普通 WPF 控件一样组合库控件和原生控件：

```xml
<Window
    xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
    xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
    xmlns:sui="clr-namespace:SUI;assembly=SUI">
    <StackPanel Margin="24">
        <TextBlock Margin="0,0,0,12" Text="欢迎使用 SUI" />
        <Button Content="保存" Style="{StaticResource SUI.Button.Primary}" />
        <sui:SUICard
            Margin="0,16,0,0"
            Title="项目状态"
            Description="SUI 控件可以和 WPF 原生控件组合使用。"
            IconText="S" />
    </StackPanel>
</Window>
```

`SUINavigationView` 使用 `SUI.Navigation` 命名空间，导航和右侧页面如何映射由宿主应用决定。普通原生控件的样式资源、导航示例和全部属性见本手册后续章节。

### 4. 运行控件示例

克隆仓库后，在仓库根目录执行以下命令可运行 SUI Gallery：

```powershell
dotnet run --project .\samples\SUI.Gallery\SUI.Gallery.csproj -f net10.0-windows
```

将 `-f` 改为 `net48` 或 `net8.0-windows` 可检查对应版本；Gallery 首页会显示当前编译目标。GitHub Release 将分别提供三个框架的 Gallery ZIP，现代 .NET 版本为依赖框架的 win-x64 发布，需安装对应 Desktop Runtime。

Gallery 提供概览、按钮与命令、输入与选择、数据与布局、容器与反馈、应用导航、设计基础七个页面。19 组展示均使用真实 SUI 控件，可以直接体验外观、交互状态和操作反馈。Gallery 专注运行效果，接入方法、代码示例与 API 参考统一在本手册中查阅。

- **快速定位**：按 `Ctrl+K` 搜索中文名称、控件名或样式名（例如 `Button`、`开关`、`DataGrid`），按 `Enter` 打开首个匹配分类，按 `Esc` 清空搜索。
- **交互体验**：按钮试验台可实时切换文字、视觉变体和禁用状态；输入页可以验证名称并保存演示设置；数据页提供 200 行数据、筛选、排序、多选与两个方向的布局调整；反馈页可以启动、暂停和重置模拟任务。
- **导航与设计**：导航页演示紧凑侧栏、横向图文侧栏及入口状态；设计基础页展示实际主题的颜色、字体、圆角和间距效果。
- **状态保留**：切换分类会保留本次会话中的示例状态；离开反馈页时模拟任务自动暂停。所有操作只影响 Gallery 演示数据。

`FileUpload` 与 `TimePicker` 当前仍是控件骨架，Gallery 概览中明确标注其状态，暂未提供完整交互示例。

## 接入项目

### NuGet 包引用（推荐）

常规应用集成使用 [SUI NuGet 包](https://www.nuget.org/packages/SUI)。在宿主 WPF 项目目录执行：

```powershell
dotnet add package SUI --version 0.0.3
```

如果希望安装 NuGet 源中的最新稳定版，可省略 `--version`：

```powershell
dotnet add package SUI
```

安装命令会写入 `PackageReference`，NuGet 负责还原和管理 `SUI.dll` 引用。版本号可在 NuGet 包页面核对；使用新版本前请核对其功能与目标框架。

### 本地项目引用（源码开发）

需要修改 SUI 源码或验证仓库中尚未发布的改动时，可以克隆仓库，并在宿主 WPF 项目的 `.csproj` 中引用库项目：

```xml
<ItemGroup>
    <ProjectReference Include="..\SUI\SUI.csproj" />
</ItemGroup>
```

路径需要根据宿主项目和 SUI 的实际目录层级调整。仓库中的 Gallery 使用这种方式，便于实时验证库的改动。同一宿主项目选择 `PackageReference` 或 `ProjectReference` 中的一种，避免同时引用两份 SUI。

### 引用命名空间

NuGet 包引用和本地项目引用都使用相同的程序集名称 `SUI`。XAML 中的 `assembly=SUI` 表示程序集名称，不表示安装来源，也不是 DLL 文件路径。

普通控件位于 `SUI` 命名空间：

```xml
xmlns:sui="clr-namespace:SUI;assembly=SUI"
```

导航控件位于 `SUI.Navigation` 命名空间：

```xml
xmlns:suiNav="clr-namespace:SUI.Navigation;assembly=SUI"
```

### 合并公共样式

SUI 为 WPF 原生控件提供了一整套隐式样式。在 `App.xaml` 中合并一次 `SUIStyles.xaml`，整个应用内的 `Button`、`TextBox`、`ComboBox`、`DataGrid` 等控件就会自动换上 SUI 外观，无需逐个指定 `Style`：

```xml
<Application.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="/SUI;component/SUIStyles.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</Application.Resources>
```

`SUINavigationView` 的默认样式位于 [`../Themes/Generic.xaml`](../Themes/Generic.xaml)，WPF 会通过默认样式键自动加载，不需要在应用中重复合并。

## `SUICard` 卡片控件

`SUICard` 是一个轻量卡片控件，适合展示应用入口、状态摘要或功能概览。它继承自 `UserControl`，通过依赖属性提供基本配置。

### 基本用法

```xml
<sui:SUICard
    Title="项目状态"
    Description="这是一个可复用的 WPF 卡片"
    IconText="S" />
```

### 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `IconSource` | `ImageSource?` | `null` | 图标图片。设置后会替换默认的文字图标。 |
| `Title` | `string` | `标题` | 卡片标题。 |
| `Description` | `string` | `略` | 卡片描述，支持换行。 |
| `IconText` | `string` | `S` | 没有 `IconSource` 时显示的占位文字。 |
| `IconColor` | `Brush` | `#4C79FF` | 默认文字图标的背景画刷。 |

### 数据绑定

所有上述属性都是依赖属性，可以直接绑定到 ViewModel：

```xml
<sui:SUICard
    Description="{Binding Description}"
    IconColor="{Binding AccentBrush}"
    IconSource="{Binding IconSource}"
    IconText="{Binding IconText}"
    Title="{Binding Title}" />
```

如果使用图片作为 `IconSource`，请确保图片格式和资源路径已被宿主 WPF 项目正确处理。SUI 不额外提供 SVG 渲染器。

## `SUINavigationView` 导航控件

`SUINavigationView` 是一个“图标在上、标题在下”的窄侧边导航壳。它只负责导航项目、选中状态和左右布局；右侧页面由宿主应用提供，因此不会反向依赖业务页面。

### 基本接入

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}">
    <ContentControl Content="{Binding CurrentPage}" />
</suiNav:SUINavigationView>
```

### 准备导航数据

最简单的方式是使用 `SUINavigationItem`：

```csharp
using System.Collections.ObjectModel;
using SUI.Navigation;

public ObservableCollection<SUINavigationItem> NavigationItems { get; } =
[
    new()
    {
        Key = "home",
        Title = "主页",
        IconGlyph = "\uE80F",
        ToolTip = "进入主页"
    },
    new()
    {
        Key = "settings",
        Title = "设置",
        IconGlyph = "\uE713",
        ToolTip = "打开设置"
    }
];

public SUINavigationItem? SelectedNavigationItem { get; set; }
```

如果运行时需要从代码修改 `SelectedNavigationItem` 并刷新界面，该属性应通过 `INotifyPropertyChanged`、依赖属性或宿主项目已有的 MVVM 属性机制实现通知。

### 将导航 Key 映射到页面

建议由宿主应用维护页面工厂，并按 `Key` 缓存页面实例：

```csharp
private readonly Dictionary<string, Func<UserControl>> _pageFactories = new()
{
    ["home"] = static () => new HomePageView(),
    ["settings"] = static () => new SettingsPageView()
};

private readonly Dictionary<string, UserControl> _pageCache = [];

private void NavigationRoot_SelectionChanged(object sender, SelectionChangedEventArgs e)
{
    if (NavigationRoot.SelectedItem is not SUINavigationItem item ||
        !_pageFactories.TryGetValue(item.Key, out Func<UserControl>? factory))
    {
        PageContent.Content = null;
        return;
    }

    if (!_pageCache.TryGetValue(item.Key, out UserControl? page))
    {
        page = factory();
        _pageCache[item.Key] = page;
    }

    PageContent.Content = page;
}
```

对应的 XAML 可以监听控件冒泡的 `SelectionChanged` 事件：

```xml
<suiNav:SUINavigationView
    x:Name="NavigationRoot"
    ItemsSource="{Binding NavigationItems}"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}"
    SelectionChanged="NavigationRoot_SelectionChanged">
    <ContentControl x:Name="PageContent" />
</suiNav:SUINavigationView>
```

### `SUINavigationView` 属性

| 属性/事件 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemsSource` | `IEnumerable?` | `null` | 导航项目集合，也可以使用自定义数据模型。 |
| `SelectedItem` | `object?` | `null` | 当前选中项目，默认双向绑定。 |
| `ItemTemplate` | `DataTemplate?` | 内置模板 | 自定义导航项的显示内容。 |
| `ItemContainerStyle` | `Style?` | 内置样式 | 自定义导航项容器的间距、圆角、悬停和选中效果。 |
| `PaneWidth` | `GridLength` | `56` | 左侧导航栏宽度。 |
| `IconSize` | `double` | `18` | 默认模板中的图标字号。 |
| `ItemHeight` | `double` | `54` | 每个导航项的高度。 |
| `LabelFontSize` | `double` | `11` | 默认模板中的标题字号。 |
| `SelectionChanged` | 路由事件 | — | 用户点击或代码改变选中项时触发。 |

尺寸配置示例：

```xml
<suiNav:SUINavigationView
    ItemsSource="{Binding NavigationItems}"
    PaneWidth="64"
    IconSize="20"
    ItemHeight="58"
    LabelFontSize="12"
    SelectedItem="{Binding SelectedNavigationItem, Mode=TwoWay}" />
```

### `SUINavigationItem` 属性

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `Key` | `string` | 空字符串 | 项目唯一标识，用于页面路由或页面缓存。 |
| `Title` | `string` | 空字符串 | 导航标题。 |
| `IconGlyph` | `string` | 空字符串 | `Segoe Fluent Icons` 字体字符。 |
| `ToolTip` | `string?` | `null` | 鼠标停留时的提示文字。 |
| `IsEnabled` | `bool` | `true` | 是否允许选择该项目。 |
| `IsVisible` | `bool` | `true` | 是否显示该项目。 |

`SUINavigationItem` 实现了 `INotifyPropertyChanged`，运行时修改标题、图标、启用状态或显示状态会刷新界面。

### 自定义项目模板

`ItemsSource` 不强制必须使用 `SUINavigationItem`。如果导航数据提供图片或其他图标来源，可以完全替换默认模板：

```xml
<suiNav:SUINavigationView.ItemTemplate>
    <DataTemplate>
        <StackPanel VerticalAlignment="Center">
            <Image
                Width="18"
                Height="18"
                HorizontalAlignment="Center"
                Source="{Binding IconSource}" />
            <TextBlock
                Margin="0,2,0,0"
                HorizontalAlignment="Center"
                Text="{Binding Title}" />
        </StackPanel>
    </DataTemplate>
</suiNav:SUINavigationView.ItemTemplate>
```

### 导航使用建议

1. `Key` 在同一个导航列表中保持唯一，并与宿主应用的页面路由表一致。
2. 默认图标依赖 Windows 的 `Segoe Fluent Icons` 字体；需要图片或自定义矢量图时使用 `ItemTemplate`。
3. 建议为 `SelectedItem` 设置初始值，避免程序启动时右侧内容为空。
4. 如果不需要前进/后退历史，建议使用 `ContentControl`，不必使用 `Frame`。

## 样式资源

### 总入口

[`SUIStyles.xaml`](../SUIStyles.xaml) 按顺序合并 `Themes/Colors.xaml`（主题令牌，必须第一个）和 `Styles/` 下的所有样式文件。合并后分两类使用：

- **隐式样式**：没有 `x:Key`，对应类型的控件自动生效，包括 `Button`、`ToggleButton`、`TextBox`、`PasswordBox`、`ComboBox`、`ComboBoxItem`、`CheckBox`、`RadioButton`、`TabControl`、`TabItem`、`ListBox`、`ListBoxItem`、`ScrollBar`、`ScrollViewer`、`Menu`、`ContextMenu`、`MenuItem`、`Separator`、`ToolTip`、`ProgressBar`、`DataGrid`、`TreeViewItem`。
- **显式样式**：需要 `Style="{StaticResource ...}"` 指定，包括 `SUI.Button.Primary`、`SUI.Button.Ghost`、`SUI.Button.Danger`、`SwitchCheckBoxStyle`（别名 `SUI.Switch`）、`CustomGridSplitterStyle`、`SUI.GridSplitter.Horizontal`、`CommonDataGridStyle`、`SUITreeViewItemStyle`。

自己为控件写样式时，用 `BasedOn="{StaticResource {x:Type Button}}"` 继承 SUI 的隐式样式，不会丢失原有外观：

```xml
<Style x:Key="MyButton" TargetType="Button" BasedOn="{StaticResource {x:Type Button}}">
    <Setter Property="MinWidth" Value="96" />
</Style>
```

### 默认主题

导航控件默认主题和颜色资源位于 [`Themes/Generic.xaml`](../Themes/Generic.xaml)。局部属性、`ItemTemplate` 和 `ItemContainerStyle` 的设置优先于默认样式，不需要直接修改库内主题文件。

## 主题令牌

所有颜色、字体、圆角、间距都定义在 [`Themes/Colors.xaml`](../Themes/Colors.xaml)，样式文件和你自己的界面都应该引用这些资源，不要写死颜色。引用方式统一为 `{StaticResource 键名}`。

| 类别 | 键 | 用途 |
| --- | --- | --- |
| 强调色 | `SUI.Brush.Accent` / `AccentHover` / `AccentPressed` / `TextOnAccent` | 主按钮、选中标记、焦点高亮；`TextOnAccent` 是强调色背景上的文字。 |
| 底色 | `SUI.Brush.Background` / `Surface` / `SurfaceAlt` | 窗口底、控件与卡片底、次级底（表头、交替行）。 |
| 文字 | `SUI.Brush.Text` / `TextSecondary` / `TextDisabled` | 正文、次要文字、禁用文字。 |
| 边框 | `SUI.Brush.Border` / `BorderHover` / `Focus` | 常态边框、悬停边框、键盘焦点外框。 |
| 状态 | `SUI.Brush.Hover` / `Pressed` / `Selected` / `Disabled` | 悬停、按下、选中、禁用底色。 |
| 语义色 | `SUI.Brush.Success` / `Warning` / `Danger` / `DangerHover` / `DangerPressed` / `Info` | 状态提示与危险操作。 |
| 字体 | `SUI.Font.Family` / `Mono` / `Icon`，`SUI.Font.Size.Body`(13) / `Caption`(12) / `Title`(16) | 正文字体、等宽字体、图标字体与字号。 |
| 圆角 | `SUI.Radius.Control`(4) / `Panel`(8) | 控件圆角、面板圆角。 |
| 尺寸与间距 | `SUI.Control.Height`(32)、`SUI.Space.1`~`4`(4/8/12/16) | 控件标准高度与间距。 |

在自己的页面里使用示例：

```xml
<Border Background="{StaticResource SUI.Brush.Surface}"
        BorderBrush="{StaticResource SUI.Brush.Border}"
        BorderThickness="1"
        CornerRadius="{StaticResource SUI.Radius.Panel}">
    <TextBlock Foreground="{StaticResource SUI.Brush.TextSecondary}" Text="说明文字" />
</Border>
```

要统一调整库的配色，可以修改 `Colors.xaml` 中的画刷值（保持键名不变）并重新构建。当前样式使用 `StaticResource`，不要将此理解为已提供运行时明暗主题切换 API。网页说明书的明暗切换仅作用于文档页面。

## 原生控件样式

以下原生控件样式由 `SUIStyles.xaml` 统一加载。其中 `Switch` 和 `GridSplitter` 需要显式指定样式，其余按下文说明使用隐式样式。交互控件按适用场景提供悬停、按下、键盘焦点和禁用反馈，具体状态以对应控件实现为准。

### Button 与 ToggleButton

默认按钮：`Surface` 底、1px 边框、圆角 4、最小高度 32，内边距 `12,0`。`ToggleButton` 选中时显示 `Selected` 底和强调色边框。

```xml
<Button Content="普通按钮" />
<Button Content="保存" Style="{StaticResource SUI.Button.Primary}" />
<Button Content="取消" Style="{StaticResource SUI.Button.Ghost}" />
<Button Content="删除" Style="{StaticResource SUI.Button.Danger}" />
<ToggleButton Content="开关按钮" IsChecked="True" />
```

| 样式键 | 外观 | 适用场景 |
| --- | --- | --- |
| 无（隐式） | 白底灰边框 | 普通操作。 |
| `SUI.Button.Primary` | 强调色底、白字、无边框 | 页面主要操作，一个区域建议只放一个。 |
| `SUI.Button.Ghost` | 透明底无边框，悬停才显示底色 | 取消、工具栏等次要操作。 |
| `SUI.Button.Danger` | 红底白字 | 删除等不可恢复操作。 |

### TextBox 与 PasswordBox

`Surface` 底、1px 边框、圆角 4，文字垂直居中。悬停时边框变深；获得焦点时底边加粗为 2px 强调色；`IsReadOnly` 时底色为 `SurfaceAlt`；选区使用强调色。`AcceptsReturn="True"` 的多行输入框会自动使用更大的上下内边距。

```xml
<TextBox Text="{Binding Name, UpdateSourceTrigger=PropertyChanged}" />
<PasswordBox />
<TextBox AcceptsReturn="True" Height="96" TextWrapping="Wrap" />
```

**数据校验**：绑定校验失败（`Validation.HasError`）时，边框变红，并去掉系统默认的红色外框；把鼠标放在输入框上会通过 ToolTip 显示错误信息。校验规则（`ValidationRules`、`INotifyDataErrorInfo` 或 `IDataErrorInfo`）由你的绑定提供。

### ComboBox

外观与 TextBox 一致，右侧是矢量下拉箭头，下拉面板带圆角和轻阴影。同时支持不可编辑和 `IsEditable="True"` 的可编辑模式。

```xml
<ComboBox SelectedIndex="0" MaxDropDownHeight="200">
    <ComboBoxItem Content="COM1" />
    <ComboBoxItem Content="COM2" />
</ComboBox>

<ComboBox IsEditable="True" ItemsSource="{Binding BaudRates}" Text="{Binding BaudRate}" />
```

普通模式点击框内任意位置即可展开；可编辑模式仅点击右侧按钮展开，输入区域仍可自由输入。在可编辑框的输入区域滚动鼠标滚轮可逐项切换可选项，无需先聚焦：向上选择上一项，向下选择下一项，跳过禁用项，到首尾停止；自定义文本尚未匹配选项时，向下从第一项、向上从最后一项开始。下拉面板展开后，滚轮保留列表滚动行为。此行为由隐式样式启用，可通过 `sui:ComboBoxAssist.EnableEditableMouseWheel="False"` 关闭（`sui` 指向 `clr-namespace:SUI;assembly=SUI`）。

用 `MaxDropDownHeight` 限制下拉面板高度，超出后出现细滚动条。支持方向键切换、Esc 关闭。

### CheckBox 与 RadioButton

18×18 的方框（CheckBox 圆角 4，RadioButton 为圆形）。选中后为强调色底，CheckBox 显示白色对勾，RadioButton 显示白色圆点；`IsThreeState="True"` 的不确定态显示白色短横。

```xml
<CheckBox Content="记住我" IsChecked="True" />
<CheckBox Content="全选" IsThreeState="True" IsChecked="{x:Null}" />
<RadioButton Content="选项 1" GroupName="g" IsChecked="True" />
<RadioButton Content="选项 2" GroupName="g" />
```

键盘 Space 可切换。

### Switch 开关

`SwitchCheckBoxStyle` 把 `CheckBox` 显示为 40×20 的胶囊开关，需要显式指定样式（别名 `SUI.Switch`）。它与普通 `CheckBox` 样式互不影响。`IsChecked` 为 `null` 时按“关闭”显示。

```xml
<CheckBox Content="启用通知" IsChecked="{Binding NotifyEnabled}" Style="{StaticResource SwitchCheckBoxStyle}" />
```

### TabControl

顶部标签页。选中标签文字为 `Text` 色并带 2px 强调色下划线，未选中为 `TextSecondary`；内容区只有顶部一条分隔线。仅保证 `TabStripPlacement="Top"`；其他方向不会崩溃，但不保证外观。

```xml
<TabControl>
    <TabItem Header="常规"><TextBlock Text="常规内容" /></TabItem>
    <TabItem Header="高级"><TextBlock Text="高级内容" /></TabItem>
</TabControl>
```

### ListBox

`Surface` 底、1px 边框、圆角 4，条目最小高度 32。选中项为 `Selected` 底，窗口失去焦点后依然保持选中底色，`SelectionMode="Extended"` 多选时可清楚辨认。

```xml
<ListBox ItemsSource="{Binding Items}" SelectedItem="{Binding Current}" SelectionMode="Extended" />
```

`SUINavigationView` 内部的 ListBox 使用自己的显式样式，不受此隐式样式影响。

### ScrollBar 与 ScrollViewer

滚动条宽/高为 10，透明轨道保留完整的拖动命中区域；滑块以居中的细圆角条显示，悬停或拖动时加宽并加深。垂直和水平都支持，保留鼠标滚轮与翻页命令。`DataGrid`、`ListBox`、多行 `TextBox`、`ComboBox` 下拉里的滚动条外观一致。

```xml
<ScrollViewer HorizontalScrollBarVisibility="Auto" VerticalScrollBarVisibility="Auto">
    <!-- 内容 -->
</ScrollViewer>
```

### Menu、ContextMenu、MenuItem、Separator

菜单栏、右键菜单和子菜单都使用圆角面板和轻阴影。条目布局为 图标列 ｜ 标题 ｜ 快捷键 ｜ 子菜单箭头；`IsCheckable` 且选中时显示对勾；`InputGestureText` 显示为次要色。`Separator` 为 1px 分隔线。Alt 访问键保持原生行为。

```xml
<Menu>
    <MenuItem Header="文件(_F)">
        <MenuItem Header="打开" InputGestureText="Ctrl+O" />
        <MenuItem Header="自动保存" IsCheckable="True" IsChecked="True" />
        <Separator />
        <MenuItem Header="退出" />
    </MenuItem>
</Menu>

<Button Content="右键我">
    <Button.ContextMenu>
        <ContextMenu>
            <MenuItem Header="复制" />
            <MenuItem Header="粘贴" />
        </ContextMenu>
    </Button.ContextMenu>
</Button>
```

### ToolTip

`Surface` 底、1px 边框、圆角 4、带轻阴影，最大宽度 320，长文字自动换行。字符串和自定义内容都可使用。

```xml
<Button Content="提示" ToolTip="这是一段提示文字" />

<Button Content="自定义">
    <Button.ToolTip>
        <StackPanel>
            <TextBlock FontWeight="SemiBold" Text="标题" />
            <TextBlock Text="详细说明" TextWrapping="Wrap" />
        </StackPanel>
    </Button.ToolTip>
</Button>
```

### ProgressBar

高 4 的细进度条，轨道为边框色，指示条为强调色。`IsIndeterminate="True"` 时显示往复移动的动画条，控件隐藏或禁用时动画自动停止。

```xml
<ProgressBar Value="{Binding Progress}" Maximum="100" />
<ProgressBar IsIndeterminate="True" />
```

### DataGrid

隐式样式已覆盖 `DataGrid`，也可使用显式键 `CommonDataGridStyle`。表头为 `SurfaceAlt` 底，并延伸到右侧垂直滚动条槽位，使表格顶边连续铺满；行有交替底色；悬停为 `Hover` 底；选中行为 `Selected` 底，窗口失焦后依然保持。表头支持排序箭头（升序/降序小三角）。保持了行虚拟化，大数据量滚动流畅，不要在行或单元格里使用 `Effect`。

```xml
<DataGrid ItemsSource="{Binding Rows}"
          AutoGenerateColumns="False"
          SelectionMode="Extended"
          SelectionUnit="FullRow">
    <DataGrid.Columns>
        <DataGridTextColumn Header="编号" Binding="{Binding Id}" />
        <DataGridTextColumn Header="名称" Binding="{Binding Name}" Width="*" />
    </DataGrid.Columns>
</DataGrid>
```

### GridSplitter

1px 细分隔线，悬停和拖动时变为强调色，线宽不变，不会引起布局抖动。透明命中区由 `Width`/`Height` 决定，建议设为 8 以上便于拖动。

```xml
<!-- 竖向，用于左右分栏 -->
<GridSplitter Grid.Column="1" Width="8" HorizontalAlignment="Center"
              Style="{StaticResource CustomGridSplitterStyle}" />

<!-- 横向，用于上下分区 -->
<GridSplitter Grid.Row="1" Height="8"
              Style="{StaticResource SUI.GridSplitter.Horizontal}" />
```

两种样式都预设 `ShowsPreview="True"`。拖动时显示强调色细线与中央短握柄作为位置预览，松开鼠标后再调整布局；横向与竖向样式分别提供对应的预览样式。

## `TreeStyles` 树样式

`TreeStyles` 为 WPF 原生 `TreeViewItem` 提供展开箭头、文件夹和叶子节点图标、层级引导线、悬停、选中、键盘焦点和禁用状态。合并 `SUIStyles.xaml` 后，普通 `TreeView` 的条目会自动使用该样式；需要显式指定时仍可使用 `SUITreeViewItemStyle`。

节点模型和显示模板由宿主应用决定。SUI 不定义 `ItemsSource` 的数据字段，也不提供固定的节点 `DataTemplate`。

### 基本用法

宿主应用合并 `/SUI;component/SUIStyles.xaml` 后，为自己的节点模型定义层级模板。以下示例使用 `Name` 和 `Children` 字段：

```xml
<TreeView
    xmlns:sui="clr-namespace:SUI;assembly=SUI"
    ItemsSource="{Binding Nodes}"
    sui:TreeStyles.ItemMinHeight="36"
    sui:TreeStyles.ItemCornerRadius="8"
    sui:TreeStyles.IconSize="17"
    sui:TreeStyles.ItemFontSize="13">
    <TreeView.ItemTemplate>
        <HierarchicalDataTemplate ItemsSource="{Binding Children}">
            <TextBlock Text="{Binding Name}" />
        </HierarchicalDataTemplate>
    </TreeView.ItemTemplate>
</TreeView>
```

如果需要显式复用带 key 的容器样式，可设置 `ItemContainerStyle="{StaticResource SUITreeViewItemStyle}"`。宿主也可以在自己的层级模板中显示额外字段，例如 OI 编号，并使用 `SUI.Brush.TextSecondary` 设置次要文字颜色。

### 可配置布局属性

以下四个附加属性只控制布局，设置在 `TreeView` 上后会传递给内部的 `TreeViewItem`：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `ItemMinHeight` | `double` | `36` | 节点最小高度。 |
| `ItemCornerRadius` | `CornerRadius` | `8` | 节点背景圆角。 |
| `IconSize` | `double` | `17` | 文件夹和叶子图标尺寸。 |
| `ItemFontSize` | `double` | `13` | 节点标题字号。 |

悬停、选中、焦点、禁用状态和图标颜色由 `Colors.xaml` 统一提供，不需要在 `TreeView` 上配置颜色附加属性。

## 转换器

命名空间：

```csharp
using SUI.Converters;
```

| 类型 | 用途 |
| --- | --- |
| `BoolToVisibilityConverter` | `true` 转为 `Visible`，其他值转为 `Collapsed`。反向转换时只有 `Visible` 为 `true`。 |
| `ColorStringToBrushConverter` | 将 `#4C79FF` 等颜色字符串转换为 `SolidColorBrush`；无效值使用默认蓝色。 |
| `EqualityConverter` | 比较两个绑定值是否相等；可直接使用静态实例 `EqualityConverter.Instance`。 |

## 构建与排查

### 构建命令

在仓库根目录执行：

```powershell
dotnet build SUI.slnx
```

解决方案包含 SUI 库与 `samples/SUI.Gallery` 展示应用。使用 `dotnet build SUI.slnx` 构建；运行 Gallery 可直接检查控件外观、状态和交互效果。

### 常见问题

**控件无法解析或 XAML 报命名空间错误**

确认宿主项目已经安装 `SUI` NuGet 包或添加本地项目引用，并检查命名空间是否分别使用 `SUI` 和 `SUI.Navigation`。使用 NuGet 时，先确认包还原成功，且安装版本包含所用的 API。

**导航控件没有默认样式**

确认 `Themes/Generic.xaml` 仍作为项目资源参与编译，并且宿主项目引用的是当前 SUI 程序集。

**图标显示为空**

使用 `IconGlyph` 时确认系统存在 `Segoe Fluent Icons` 字体；使用图片时确认 `ImageSource` 的资源路径和 Build Action 正确。

**样式资源找不到**

确认已经合并 `/SUI;component/SUIStyles.xaml`，并且资源键拼写与 `Styles/` 文件中的定义一致。
