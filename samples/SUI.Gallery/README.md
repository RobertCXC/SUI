# SUI Gallery

Gallery 用于展示控件的实际外观、状态与交互效果。使用说明和 API 参考统一放在仓库的 `doc/使用手册.md` 中。

在仓库根目录运行：

```powershell
dotnet run --project .\samples\SUI.Gallery\SUI.Gallery.csproj -f net10.0-windows
```

## 展示约定

Gallery 与库同时面向 `net48`、`net8.0-windows`、`net10.0-windows`。运行时必须用 `-f` 选择目标；首页显示当前编译目标。`net48` 使用 Framework 4.8 / 4.8.1，现代目标使用对应的 Desktop Runtime。主要验收系统为 Windows 10 / 11。

- 使用真实库控件与主题资源，保持预览与实际实现一致。
- `Examples/` 放置可操作的展示控件；页面使用 `Controls/Example` 组织标题、效果预览与操作提示。
- Gallery 不提供源码面板、代码生成、代码复制、项目导出或接入模板。
- 展示说明应解释控件的用途、视觉状态与操作方式；接入方法、资源名和实现原理留在使用手册中。
- 可用操作应有可见结果。模拟操作只修改会话数据，不读写业务文件。
- 同时覆盖常用变体、禁用与选择状态；焦点和悬停通过真实键鼠操作体验。
- 颜色来自 `SUI.Brush.*`。Gallery 自己的标题与留白在 `App.xaml` 中集中维护，不能修改库样式来迁就展示页。
- `MainWindow` 管理分类目录、搜索和页面缓存；嵌套导航事件必须检查来源，避免触发外层路由。
- 页面缓存保留输入、滚动与选择状态。后台计时和动画必须在页面不可见时停止。
- `FileUpload` 与 `TimePicker` 是控件骨架，不以虚构预览暗示已完成的能力。

## 验收

1. `dotnet build SUI.slnx`：0 错误、0 警告。
2. 首页入口能打开对应分类；Ctrl+K 支持中英文搜索，Enter 跳转，Esc 清空；无结果时显示明确提示。
3. 每组展示只包含运行效果与操作提示，不出现代码面板或源码复制入口；按钮试验台的文字、变体和禁用选项能即时改变预览。
4. 输入页校验无效名称、修正并保存；检查下拉键盘操作、复选与单选摘要、多选列表和滚动条。
5. 数据页检查 200 行数据、搜索、空结果、树筛选、表头排序、多选、Ctrl+C、横竖分隔线与失焦后的选中效果。
6. 反馈页检查卡片换行、标签切换、菜单与子菜单、右键菜单、ToolTip、任务开始 / 暂停 / 完成 / 重置；运行中离开再返回应保持暂停。
7. 导航页检查上方菜单独立滚动时帮助、设置仍固定在底部；上下分组共用选中状态与页面切换，自定义图文模板同时应用于两组。检查内嵌导航只更新内嵌内容，以及入口隐藏、禁用、重新启用和示例的选择回退。
8. 设计基础页检查色板、字体、圆角和间距的实际视觉效果；以默认窗口、最小窗口和最大化窗口检查裁切与滚动。
